# 학습 화면 명세

## 문서 정보

- 문서 상태: `draft`
- 요구사항 상태: 영역 역할만 확인됨, 최신 학습자료·퀴즈 정책에 맞춘 화면 구조 재검토 필요
- 대상 플랫폼: 모바일 WebView 우선
- 관련 기능: [학습자료 만들기](../features/02-content-import.md), [퀴즈 생성·풀이·결과·복습](../features/03-quiz-generation.md)
- 관련 흐름: [학습자료 만들기](../flows/content-import.md), [퀴즈 생성부터 복습까지](../flows/quiz-solving.md)

> 동기화 주의: 아래 정보 구조와 상태 목록은 최신 기능명세·흐름을 반영하기 전의 초안이다. 충돌하는 항목은 구현 기준으로 사용하지 않으며, 확정된 제품 정책은 위 연결 문서가 책임진다.

## 확정 사항

- 하단 `학습`은 학습 자료, 문제 만들기와 복습을 한 영역에서 다룬다.
- 자료 입력은 직접 붙여넣기와 Notion 단일 페이지 일회성 복사를 지원한다. 로컬 파일 업로드와 Notion 동기화는 MVP 비범위다.
- 문제 유형은 객관식, 빈칸 채우기, 단답형, 서술형을 지원한다.
- 문제 생성 시 쉬움·보통·어려움과 최대 5·10·15문제를 선택할 수 있고 기본 최대값은 10이다.

## 설계 가정

- 화면 상단의 `새 학습` 행동과 기존 학습 자료 목록을 중심으로 구성한다.
- 복습 대상, 문제 생성 전, 풀이 중, 완료 상태를 필터나 구분 가능한 상태로 제공하되 별도 하단 탭을 만들지 않는다.
- 자료 하나를 선택하면 원문, 생성된 문제 세트와 학습 이력을 한 맥락에서 확인한다.

## 미결정 사항

- 목록 기본 정렬과 검색·필터 범위
- 자료 삭제가 문제·풀이 기록에 미치는 영향

## 제안 정보 구조

1. 화면 제목과 새 학습 행동
2. 진행 중인 학습 또는 복습 대상 요약
3. 상태·출처별 필터와 검색
4. 학습 자료 목록
5. `홈`, `학습`, `프로필` 하단 내비게이션

이 구조는 승인 전 초안이다. 세부 화면과 가져오기·문제 풀이 하위 흐름은 각각 별도 명세로 확장한다.

## 필수 상태

- 자료가 없는 첫 사용자
- 자료 불러오는 중과 목록 갱신 실패
- Notion 페이지 복사·저장 중인 자료
- 문제 생성 전, 생성 중, 생성 실패, 풀이 가능
- 풀이 중, 복습 대상, 학습 완료
- 검색·필터 결과 없음

## 접근성·WebView 기준

- 상태를 배지 색상만으로 구분하지 않고 텍스트로 제공한다.
- 자료 입력 컨트롤은 터치뿐 아니라 키보드와 보조기기에서도 입력 방식과 조건을 이해할 수 있어야 한다.
- 긴 자료명과 생성 진행 상태가 작은 화면에서 핵심 행동을 밀어내지 않게 한다.
- 하단 탭의 현재 위치와 안전 영역을 보존한다.

## 비범위

- 랭킹, 친구가 만든 문제 탐색과 상점
- Notion·LLM 연동의 기술 계약 세부사항
