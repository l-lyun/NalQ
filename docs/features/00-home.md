# 기능명세: 홈

- 상태: 초안
- 관련 원장: [전역 내비게이션](../product/navigation.md)

## 사용자 문제

사용자는 앱을 열었을 때 자료 목록과 여러 기능 사이에서 무엇을 먼저 해야 할지 판단해야 한다. 이전 학습 맥락을 기억하지 못하면 학습을 재개하기 어렵다.

## 목표

사용자가 홈에서 현재 가장 가치 있는 학습 행동을 이해하고 한 번의 선택으로 시작하게 한다.

## 범위

- 사용자 상태에 맞는 대표 다음 행동 한 개
- 새 학습 시작 진입점
- 필요한 복습의 요약과 진입점
- 최근 학습자료
- 오늘의 학습 활동 요약
- 데이터가 없는 첫 사용자 상태와 각 섹션의 빈 상태

## 비범위

- 전체 학습자료 관리
- 상세 통계와 계정 설정
- 경험치, 랭킹, 친구, 꾸미기의 초기 구현

## 핵심 규칙

- 홈의 첫 번째 강조 요소는 기능 목록이 아니라 `다음 학습 행동`이다.
- 다음 행동 후보의 제안 우선순위는 [전역 내비게이션](../product/navigation.md)의 초안을 따른다.
- 복습과 학습자료는 홈에서 요약만 제공하고 상세 탐색은 학습 탭으로 연결한다.
- 새 사용자는 빈 카드 여러 개 대신 학습자료 가져오기를 시작하도록 안내한다.
- 불러오기 실패 등 일부 데이터가 없더라도 가능한 다른 홈 행동은 사용할 수 있어야 한다.

## 주요 상태

| 상태 | 기대 동작 |
| --- | --- |
| 첫 방문 | 자료를 가져오는 첫 행동과 지원 입력 방식을 설명한다. |
| 미완료 풀이 있음 | 이어 풀기를 대표 행동으로 제안한다. |
| 복습 대상 있음 | 복습할 규모와 시작 행동을 보여준다. |
| 문제 없는 자료 있음 | 해당 자료로 문제 만들기를 제안한다. |
| 최근 학습만 있음 | 최근 자료를 다시 열 수 있다. |
| 홈 데이터 로딩 실패 | 재시도와 가능한 독립 행동을 제공한다. |

## 수용 기준

- 로그인한 사용자는 홈에서 홈·학습·프로필 탭을 식별하고 이동할 수 있다.
- 사용자의 학습 상태가 하나 이상이면 홈은 대표 다음 행동을 하나 보여준다.
- 대표 행동을 선택하면 해당 자료 또는 풀이 맥락이 유지된 다음 단계로 이동한다.
- 학습 이력이 없는 사용자는 지원되는 방식으로 자료를 가져오는 흐름을 시작할 수 있다.
- 복습 요약에서 복습 풀이로, 최근 자료에서 해당 자료 상세로 이동할 수 있다.
- 부분 오류가 발생했을 때 오류 원인 또는 재시도 행동을 알 수 있다.

## 열린 질문

- `오늘의 학습`에 보여줄 지표와 일자 기준
- 복습 대상을 결정하는 규칙
- 여러 미완료 풀이가 있을 때 대표 항목을 정하는 기준
- 홈에서 자료 가져오기 방식 선택을 바로 노출할지 학습 탭으로 이동할지
