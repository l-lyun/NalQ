# 용어집

- 상태: 초안

| 용어 | 의미 | 사용 시 주의 |
| --- | --- | --- |
| 학습자료 | 사용자가 가져온 하나의 글 또는 학습 가능한 콘텐츠 단위 | 원본, 노트, 문서를 혼용하지 않는다. |
| 원문 | 문제와 설명의 근거가 되는 학습자료의 텍스트 | 외부 출처의 전체 페이지와 정규화된 본문을 구분할 필요가 있으면 계약에서 명시한다. |
| 가져오기 | Notion, 파일, 붙여넣기에서 텍스트를 받아 학습자료로 만드는 행위 | 장기 동기화를 뜻하는 `연동`과 구분한다. |
| Notion 연결 | 사용자가 허용한 Notion 콘텐츠를 선택해 가져올 수 있게 하는 과정 | 자동 동기화 여부는 아직 확정하지 않았다. |
| 문제 세트 | 한 학습자료와 생성 조건을 바탕으로 만든 문제 묶음 | 사용자에게 더 자연스러운 명칭은 UX 설계에서 검토한다. |
| 문제 유형 | 객관식, 단답형, 주관식 또는 이를 함께 쓰는 혼합형 | 혼합형의 비율은 미확정이다. |
| 난이도 | 문제의 회상·추론 부담을 사용자가 조절하는 조건 | 단계 수와 명칭은 미확정이다. |
| 풀이 세션 | 사용자가 문제 세트를 풀기 시작해 제출 또는 중단하기까지의 기록 | 자동 저장 시점은 계약에서 정한다. |
| 채점 | 사용자 답을 정답 기준과 비교해 결과 및 설명을 만드는 과정 | 주관식 결과는 모델 판단의 불확실성을 고려한다. |
| 복습 | 이전 풀이 결과를 바탕으로 다시 확인하거나 문제를 푸는 학습 행동 | 별도 하단 탭이 아니라 학습 영역과 홈에서 진입한다. |
| 다음 학습 행동 | 현재 상태에서 홈이 가장 우선해 제안하는 한 가지 행동 | 우선순위 규칙은 검증 전 초안이다. |
