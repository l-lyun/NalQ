# [PRD] 퀴즈 생성·풀이·결과·복습

- 관련 기능: [학습자료 가져오기](prd-content-import.md)
- 관련 흐름: [퀴즈 생성부터 복습까지의 흐름](../ux/flow-quiz-solving.md)
- 공유 계약: [학습자료·퀴즈 API 계약](../contracts/contract-api-quiz-learning.md)

## 문서 책임

이 문서는 학습자료로 퀴즈를 만들고, 풀고, 결과를 이해하고, 가장 최근 학습을 복습하는 제품 정책과 성공 조건을 정의한다. 화면 간 중단·복구·분기는 관련 흐름이, HTTP 입출력·권한·상태·멱등성·오류는 공유 계약이 책임진다.

## 사용자 문제

사용자는 읽은 자료를 실제로 이해했는지 확인할 문제를 직접 만들기 어렵고, 단순 점수만으로는 무엇을 다시 봐야 하는지 알기 어렵다. 서술형은 기계가 임의로 점수를 확정하면 결과를 신뢰하기 어렵고, 틀린 문제를 다시 풀 기회가 없으면 결과 확인이 학습으로 이어지지 않는다.

## 목표

- 사용자가 학습자료에 근거한 퀴즈를 원하는 유형·난이도·최대 문제 수로 생성해 끝까지 풀 수 있다.
- 자동 채점 가능한 답과 서술형 자기평가를 구분해 결과를 이해할 수 있다.
- 가장 최근에 완료한 본 퀴즈 회차의 미해결 문항을 다시 풀어 해결 상태로 바꿀 수 있다.

## 성공 원칙

1. **근거 우선:** 질문·정답·해설은 학습자료에서 근거를 찾을 수 있어야 한다.
2. **정직한 진행 상태:** 생성 시간을 가짜 퍼센트로 포장하지 않고, 네트워크 문제와 생성 실패를 구분한다.
3. **평가 방식의 투명성:** 자동 채점과 서술형 자기평가의 범위가 다름을 풀이 전에 알린다.
4. **학습 기록 보존:** 재생성·복습이 이전 문제 세트와 본 퀴즈 회차를 덮어쓰지 않는다.

## 범위

- 학습자료별 퀴즈 생성, 상태 확인과 실패 후 재시도
- 객관식, 빈칸 채우기, 단답형, 서술형 문제
- 기기 안 임시 풀이 보존, 한 문항씩 풀이, 최종 일괄 제출
- 자동 채점과 서술형 자기평가
- 결과 요약, 문항별 판정·해설·원문 근거
- 가장 최근 완료한 본 퀴즈 회차의 미해결 문항 복습
- 랜딩, 첫 서술형, 결과에서 평가·복습 방식 안내

## 비범위

- 로컬 파일 업로드
- 서버의 중간 풀이 초안 저장과 여러 기기 이어 풀기
- 문제의 Markdown, 코드, 표 렌더링
- 서술형 LLM 채점, 부분 점수 또는 자동 점수 반영
- 일일 생성·풀이 한도
- 과거 회차 선택과 여러 회차를 합친 누적 복습
- 경험치, 랭킹, 포인트 지급 정책

## 확정 정책

### 생성 조건과 결과

- 사용자는 문제 유형을 하나 이상 선택한다. 유형은 `객관식`, `빈칸 채우기`, `단답형`, `서술형`이다.
- 난이도는 `쉬움`, `보통`, `어려움` 중 하나다.
- 최대 문제 수는 필수이며 `5`, `10`, `15` 중 하나다. UI의 초기 선택값은 `10`이지만 생성 요청에서 생략하지 않는다.
- 선택한 유형은 결과에 각각 최소 한 문제 포함되어야 한다.
- 최대 문제 수를 채우기 위해 지엽적이거나 근거가 약한 문제를 만들지 않는다. 품질 기준을 충족한 실제 문제 수가 최대값보다 적어도 선택 유형이 모두 포함되면 생성 성공이다.
- 생성 결과가 0문제이거나 선택 유형 중 하나라도 빠지면 전체 생성을 실패 처리하며 사용자에게 불완전한 세트를 노출하지 않는다.
- 0문제 또는 선택 유형 누락에 따른 자료·조건 부족과, 접수 뒤 생성 작업 실패는 서로 구분해 사용자가 자료·조건을 바꿀지 그대로 재시도할지 판단할 수 있게 한다.
- 같은 학습자료에서는 동시에 하나의 생성만 진행할 수 있다.
- 재생성은 허용한다. 매번 새로운 불변 문제 세트를 만들고 이전 문제 세트와 본 퀴즈 회차를 보존한다.
- 오답 선택지는 필요한 경우 일반 지식을 활용할 수 있다. 질문, 정답과 해설은 학습자료 근거가 필수다.

### 학습자료 잠금

- 생성 요청이 접수되는 순간부터 학습자료 본문을 잠근다.
- 성공한 문제 세트가 하나도 없는 상태에서 생성에 실패하면 본문 잠금을 해제한다.
- 첫 문제 세트가 성공하면 그 학습자료의 본문은 영구적으로 수정할 수 없다. 제목은 계속 수정할 수 있다.
- 잠금 정책은 이미 생성된 문제의 근거가 나중에 바뀌는 일을 막기 위한 것이다.

### 생성 경험

- 생성 중에는 현재 작업이 명확한 차단형 오버레이를 보여주고, 완료 여부를 알 수 없는 진행 표시를 사용한다. 가짜 퍼센트는 표시하지 않는다.
- 뒤로가기는 생성 취소가 아니라 이탈 확인을 연다. 사용자가 명시적으로 나가면 화면 이탈을 허용하되 서버 생성은 계속한다.
- 사용자가 다시 진입하면 서버 상태를 기준으로 생성 중·성공·실패를 복원한다.
- 네트워크 통신 실패와 서버에서 확정된 생성 실패를 서로 다른 상태와 복구 행동으로 안내한다. 세부 분기와 조회 간격은 [퀴즈 흐름](../ux/flow-quiz-solving.md#생성-중단과-복구)이 책임진다.

### 문제 유형

| 유형 | 문제 규칙 | 평가 규칙 |
| --- | --- | --- |
| 객관식 | 보기 4개 또는 5개, 단일 정답 | 선택한 보기와 정답 보기를 서버가 비교하며 사용자가 판정을 수정하지 않음 |
| 빈칸 채우기 | 빈칸 1개 또는 2개, 텍스트와 식별 가능한 빈칸이 순서대로 이어지는 문장 | 각 빈칸 답을 정답 기준과 비교 |
| 단답형 | 짧은 일반 텍스트 응답 | 서버가 허용 답안과 규칙 기반으로 먼저 비교하고, 답을 작성한 사용자는 결과에서 판정을 수정할 수 있음. 공백·대소문자 수준만 정규화하며 LLM을 사용하지 않음 |
| 서술형 | 일반 텍스트 응답, 모범 답안과 핵심 포인트 제공 | 사용자가 `정답`, `부분 이해`, `오답`으로 자기평가. 자동 점수에서 제외 |

- 문제 본문은 MVP에서 일반 텍스트만 지원한다.
- 각 문제는 결과와 복습에서 같은 학습 주제를 식별할 수 있는 간결한 주제명을 가진다.
- 풀이 전에는 정답, 허용 답안, 모범 답안, 핵심 포인트, 해설과 원문 근거를 노출하지 않는다.
- 서술형에는 부분 점수를 부여하지 않는다. `부분 이해`는 복습 대상을 정하는 학습 상태이지 점수가 아니다.

### 본 퀴즈 풀이와 제출

- 한 화면에 한 문항을 보여주며 사용자는 이전·다음 문항으로 이동할 수 있다.
- 서버는 최종 제출 전의 현재 위치와 답안을 저장하거나 알지 못한다.
- 기기 안 임시 풀이를 계정과 문제 세트의 조합별로 7일간 보존한다. 같은 기기에서 재진입하면 `이어서 풀기` 또는 `처음부터`를 선택할 수 있다.
- 풀이 중 이탈하려 하면 임시 보존 사실과 만료 가능성을 포함해 이탈을 확인한다.
- 로그아웃하면 현재 사용자에게 속한 모든 미제출 로컬 퀴즈 기록을 삭제한다. 이후 같은 기기에서 다시 로그인해도 삭제된 기록을 이어 풀기 후보로 제시하지 않는다.
- 본 퀴즈는 마지막에 한 번에 제출하고, 이때만 불변 본 퀴즈 회차를 만든다.
- 제출 시 미응답 문항이 있으면 경고한다. `남은 문제 풀기`는 번호가 가장 낮은 미응답 문항으로 이동하며, 사용자는 미응답을 남긴 채 제출할 수도 있다.
- 제출에서 빠진 응답은 미응답 오답으로 확정한다. 미응답을 별도 성과 범주로 만들지 않는다.

### 채점 수정과 서술형 자기평가

- 객관식·빈칸·단답형은 최종 제출 시 서버가 일괄 자동 채점한다.
- 객관식 판정은 서버 채점 결과로 확정하며 사용자가 수정할 수 없다.
- 답을 작성한 단답형은 서버 자동 판정을 초기값으로 사용하되, 사용자가 결과 상세에서 `정답` 또는 `오답`으로 수정할 수 있다. 미응답 단답형은 수정할 수 없다.
- 사용자가 단답형 판정을 수정하면 수정한 판정이 해당 문항의 현재 채점 결과가 된다. 채점 점수와 복습할 문제 수도 수정한 판정으로 함께 다시 계산한다.
- 단답형 채점 결과는 다시 수정할 수 있다. 저장에 실패하면 변경 전 판정과 요약을 유지한다.
- 작성한 서술형이 하나라도 있으면 자동 채점 결과와 함께 문항별 자기평가를 요구한다.
- 서술형 자기평가 화면은 내 답, 모범 답안, 핵심 포인트, 해설과 원문 근거를 제공한다.
- 작성한 서술형은 문항별 자기평가를 저장하고 마지막 평가 후 본 퀴즈 회차를 완료한다.
- 미응답 서술형은 자동으로 `오답`이 되며 별도 자기평가 없이 복습 대상에 포함한다.
- 객관식·빈칸·단답형만 채점 점수의 분자·분모에 포함한다. 단답형 사용자 수정이 있으면 수정 판정을 분자 계산에 사용하고 서술형은 포함하지 않는다.

### 결과

- 결과는 단답형 사용자가 확정한 판정을 포함한 `채점 점수`, `서술형 자기평가 요약`, `복습할 문제 수`를 구분해 보여준다.
- 요약 아래에 모든 문항을 원래 번호 오름차순으로 보여준다.
- 문항을 선택하면 풀이 화면을 결과 읽기 모드로 재사용한다. 비활성 입력 폼처럼 보이게 하지 않고 `내 답`, `정답 또는 모범 답안`, `판정`, `해설`, `원문 근거`를 읽는 구조로 제공한다.
- 답을 작성한 단답형 상세에는 현재 판정을 보여주고 `채점 수정`을 제공한다. 수정 뒤에도 `채점 다시 수정`을 제공한다.
- 미응답 요약은 별도로 만들지 않는다. 미응답은 오답과 복습 수에 포함한다.

### 복습

- 복습 탭은 가장 최근에 완료한 본 퀴즈 회차 하나의 미해결 문항만 대상으로 한다.
- 객관식·빈칸의 서버 오답과 미응답, 단답형의 반영 판정이 오답인 문항과 미응답, 서술형의 `부분 이해`와 `오답`이 복습 대상이다.
- 복습 문항은 원래 번호 오름차순으로 제공한다.
- 복습을 시작하면 서버에 별도 복습 세션을 만든다. 원래 본 퀴즈 회차와 판정은 바꾸지 않는다.
- 문항을 답할 때마다 즉시 채점·저장한다. 서술형은 답을 작성한 뒤 같은 기준으로 자기평가한다.
- 맞거나 서술형을 `정답`으로 평가하면 `해결`, 그 밖에는 `미해결`이다.
- 한 복습 세션에서 틀린 문항을 다시 출제하지 않고 다음 문항으로 이동한다. 미해결 문항은 다음 복습에 남는다.

### 안내

- 랜딩에서 자동 채점 문제와 서술형 자기평가가 함께 있음을 알린다.
- 사용자가 첫 서술형에 도달하면 모범 답안·핵심 포인트를 보고 스스로 평가하는 방식과 자동 점수 제외를 안내한다.
- 결과에서 복습 대상의 기준과 복습하면 해결 상태가 갱신되는 방식을 안내한다.

## 상태와 예외

| 상태/조건 | 사용자에게 보이는 결과 | 복구 행동 |
| --- | --- | --- |
| 생성 중 | 차단형 오버레이와 완료 여부 미정 진행 표시 | 기다리거나 이탈 확인 후 나가기 |
| 생성 통신 실패 | 생성의 실제 서버 상태를 아직 확인하지 못했음을 안내 | 연결 복구 후 같은 작업 상태 다시 확인 |
| 생성 실패 | 생성이 실패했으며 불완전한 문제 세트는 없음을 안내 | 조건을 유지한 채 재시도하거나 자료 확인 |
| 생성 성공 | 실제 생성된 문제 수와 조건을 확인 | 본 퀴즈 시작 또는 새 문제 세트 재생성 |
| 풀이 임시 기록 있음 | 저장 시점·만료 가능성과 함께 이어서/처음부터 선택 | 같은 기기에서 재개 또는 초기화 |
| 미응답 제출 | 미응답이 오답·복습 대상이 됨을 제출 전에 안내 | 가장 낮은 미응답으로 이동 또는 그대로 제출 |
| 단답형 채점 수정 저장 실패 | 기존 판정·점수·복습 수를 유지하고 저장하지 못했음을 안내 | 같은 수정 다시 시도 |
| 서술형 자기평가 필요 | 자동 채점 결과와 남은 자기평가 수를 구분 | 문항별 평가를 완료해 결과 확정 |
| 복습 대상 없음 | 최근 완료 회차에 미해결 문항이 없음을 안내 | 새 본 퀴즈로 이동 |

## 수용 기준

- [ ] 사용자는 네 유형 중 하나 이상, 세 난이도 중 하나, 최대 5·10·15문제 중 하나를 선택해 생성을 요청할 수 있고 초기 선택값 10도 요청에 명시된다.
- [ ] 선택 유형이 모두 포함되지 않거나 유효 문제가 0개면 문제 세트가 노출되지 않으며, 최대값보다 적어도 품질과 유형 조건을 충족하면 성공한다.
- [ ] 생성 접수부터 본문이 잠기며, 첫 성공 전 실패 시에만 풀리고 첫 성공 뒤에는 제목만 수정할 수 있다.
- [ ] 생성 화면을 나가도 작업은 계속되고, 재진입 시 네트워크 오류와 서버 생성 실패가 구분된다.
- [ ] 풀이 전에 어떤 유형에서도 정답·해설·원문 근거가 노출되지 않는다.
- [ ] 같은 계정·문제 세트의 미제출 풀이를 같은 기기에서 7일 안에 이어서 또는 처음부터 시작할 수 있으며 서버에는 중간 답안이 생기지 않는다.
- [ ] 로그아웃하면 현재 사용자의 모든 미제출 로컬 퀴즈 기록이 삭제되고, 다시 로그인해도 해당 기록이 이어 풀기 후보로 나타나지 않는다.
- [ ] 미응답 제출 경고에서 가장 낮은 미응답으로 이동하거나 그대로 제출할 수 있고, 제출한 미응답은 오답·복습 대상에 포함된다.
- [ ] 객관식은 서버 판정만 사용하고, 답을 작성한 단답형은 결과 상세에서 판정을 양방향으로 다시 수정할 수 있다.
- [ ] 단답형 판정 수정 뒤에는 수정한 판정이 현재 채점 결과가 되고, 저장 성공 후 채점 점수와 복습할 문제 수가 함께 갱신된다.
- [ ] 작성한 서술형이 있으면 문항별 자기평가 후 완료되며, 서술형은 자동 점수와 부분 점수에 포함되지 않는다.
- [ ] 결과는 모든 문항을 번호 오름차순으로 제공하고, 각 문항에서 내 답·정답/모범 답안·판정·해설·원문 근거를 확인할 수 있다.
- [ ] 복습은 가장 최근 완료 회차의 미해결 문항만 번호순으로 제공하고, 즉시 판정 뒤 원본 회차를 변경하지 않은 채 해결 상태만 갱신한다.
- [ ] 랜딩·첫 서술형·결과에서 자동 채점, 자기평가와 복습 방식을 사용 시점에 맞게 확인할 수 있다.

## 계측 제안

다음 사건은 제품 가설 검증용 제안이며 출시 조건이나 목표 수치를 뜻하지 않는다.

- 생성 요청·성공·실패·명시적 이탈·재진입 후 상태 복원
- 본 퀴즈 시작·기기 임시 기록 재개·제출·자기평가 완료
- 결과 문항 상세 확인·복습 시작·복습 문항 해결
- 오류 원인은 공개 오류 코드 수준으로만 기록하고 학습자료 본문, 답안과 외부 생성 서비스 상세는 분석 사건에 넣지 않는다.
