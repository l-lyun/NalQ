- 화면명: 풀던 퀴즈 재개, 미완료 서술형 자기평가 재개
- 문서 상태: `draft`
- 대상 플랫폼: `web`, `app` WebView
- 관련 기능: [퀴즈 생성·풀이·결과·복습](../prd/prd-quiz-learning.md)
- 관련 흐름: [퀴즈 생성부터 복습까지](flow-quiz-solving.md)
- 관련 화면: [학습 메인과 새 문제 만들기 진입](screen-learning.md), [틀린 문제 다시 풀기](screen-review.md)
- 시각 기준: [OpenMD Design System](../../DESIGN.md)

## 문서 책임

이 문서는 사용자가 본 퀴즈에 다시 들어왔을 때 필요한 선택과 안내만 정의한다. 저장 위치, 동기화 여부, 재시도 방식처럼 사용자가 판단할 필요가 없는 내부 복구 상태는 화면에 노출하지 않는다.

## 확정 사항

- 제출 전 풀던 답이 있으면 `이어서 풀기`와 `처음부터`를 제공한다.
- `이어서 풀기`는 마지막으로 풀던 문항과 작성한 답을 그대로 복원한다.
- `처음부터`는 작성한 답이 지워진다는 확인을 거친다.
- 최종 제출 뒤 서술형 자기평가가 남아 있으면 기존 자기평가 화면으로 바로 이어진다.
- 제출 처리와 결과 복구는 우선 자동으로 수행한다. 성공·재시도·저장 매체는 별도 상태나 알림으로 보여주지 않는다.
- 자동 복구가 끝내 실패해 사용자의 행동이 필요할 때만 일반 오류와 `다시 시도`를 보여준다.

## 화면 1. 풀던 퀴즈 발견

기존 퀴즈 준비 화면 위에 sheet 또는 dialog를 연다.

1. 제목: `풀던 문제가 있어요`
2. 설명: `4번 문제부터 이어서 풀 수 있어요.`
3. 진행 정보: `4/10문제 진행`
4. Primary: `이어서 풀기`
5. Secondary: `처음부터`
6. Tertiary: `나가기`

마지막 저장 시각, 보존 기간, 기기 저장 여부는 보여주지 않는다. 이는 행동 선택에 필요하지 않다.

### 처음부터 확인

- 제목: `처음부터 풀까요?`
- 설명: `작성한 4문제의 답이 지워져요. 처음부터 풀까요?`
- Primary: `답안 삭제하고 시작`
- Secondary: `취소`

확인 뒤에는 별도의 `삭제 완료` 안내 없이 기존 첫 문항 풀이 화면으로 이동한다.

## 화면 2. 이어서 풀기

별도 복원 화면을 만들지 않는다. 기존 본 퀴즈 풀이 화면을 그대로 사용하고 다음만 복원한다.

- 현재 문항 번호와 진행률
- 문항별 작성 답
- 마지막으로 보고 있던 문항

`복원된 답`, `저장됨`, `저장 중`과 같은 출처·처리 안내는 표시하지 않는다.

## 화면 3. 미완료 서술형 자기평가

별도 복구 화면을 만들지 않고 기존 서술형 자기평가 화면을 그대로 사용한다.

- 상단 제목: `서술형 자기평가`
- 진행 정보: `남은 1개`
- 안내: `남은 자기평가를 이어서 해주세요.`
- 기존 구성: 문제, 내 답, 모범 답안, 핵심 포인트, 이해도 선택
- 완료 행동: 기존 자기평가 완료 CTA

서버, attempt, 저장 성공 여부는 설명하지 않는다. 사용자는 남은 평가를 이어서 하면 된다.

## 사용자에게 보이는 예외

| 조건 | 문구 | 행동 |
| --- | --- | --- |
| 결과 또는 다음 단계를 불러오지 못함 | `결과를 불러오지 못했어요. 다시 시도해 주세요.` | `다시 시도` |
| 작성 중인 답이 있는 상태에서 나가기 | `작성 중인 답이 사라져요. 나갈까요?` | `계속 풀기`, `나가기` |

오류 원인이 응답 유실, 로컬 저장, 서버 조회 중 무엇인지 구분해 보여주지 않는다.

## 반응형·접근성

- 320px부터 한 열을 유지하고 sheet·dialog와 하단 CTA가 키보드 및 safe area에 가려지지 않는다.
- 큰 글자에서 진행 정보와 버튼 문구를 줄임표로 자르지 않는다.
- modal 제목과 설명을 연결하고, 처음부터 확인은 취소가 안전한 기본 행동이 되게 한다.
- 이동 뒤에는 기존 풀이 화면의 문제 제목 또는 자기평가 제목으로 포커스를 옮긴다.

## 인수 조건

- [ ] 풀던 답이 있으면 `이어서 풀기 / 처음부터`만으로 다음 행동을 결정할 수 있다.
- [ ] 이어서 풀면 기존 풀이 화면에서 문항 위치와 답이 복원된다.
- [ ] 처음부터는 답이 지워진다는 확인 뒤 첫 문항으로 이동한다.
- [ ] 미완료 서술형 자기평가는 기존 자기평가 화면으로 바로 이어진다.
- [ ] 정상적인 복원·자동 재시도·저장 성공에는 별도 안내가 나타나지 않는다.
- [ ] 사용자가 해결해야 하는 실패에서만 일반 오류와 재시도 행동이 나타난다.

## 비범위

- 임시 답의 저장소와 만료 정책
- attempt UUID와 네트워크 재시도 방식
