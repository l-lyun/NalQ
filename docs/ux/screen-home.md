# [Screen Spec] 홈

## 문서 정보

- 문서 상태: `draft`
- 요구사항 상태: 이번 사용자 검토로 홈 정보 구조와 이동 목적지는 확인됨, 방문일 집계 의미와 일부 API 계약은 미결정
- 대상 플랫폼: 반응형 웹과 앱 WebView, 모바일 우선
- 관련 기능: [홈 PRD](../prd/prd-home.md)
- 관련 내비게이션: [제품 기반의 전역 내비게이션](../product.md#전역-내비게이션)
- 관련 화면: [학습 화면](screen-learning.md), [마이페이지 화면](screen-mypage.md)

## 목표와 범위

### 사용자 목표

- 앱에 다시 들어왔을 때 자신을 알아보는 짧은 환영 문구와 현재 가장 가치 있는 학습 행동을 바로 확인한다.
- 복습할 퀴즈와 최근 학습자료를 혼동하지 않고 올바른 관리·풀이 화면으로 이동한다.
- 학습 이력이 적어도 비어 보이는 대시보드가 아니라 지금 할 수 있는 행동을 발견한다.

### 완료 조건

사용자가 홈에서 대표 행동, 복습 퀴즈, 최근 학습자료 또는 빠른 시작 중 하나를 선택해 해당 맥락이 유지된 학습 하위 화면으로 이동하면 홈의 주 목적을 달성한 것으로 본다.

### 범위

- 사용자 환영 문구와 방문일 보조 문구
- 대표 다음 학습 행동 한 개
- 복습할 퀴즈 요약과 진입
- 최근 학습자료 최대 3개와 관리 화면 진입
- 기존 기능으로 구성한 조건부 빠른 시작
- 첫 방문, 로딩, 빈 상태, 부분 오류와 전체 오류
- 로그인 후 `홈`·`학습`·`마이페이지` 하단 내비게이션

### 비범위

- `오늘의 학습` 통계와 날짜별 집계
- 홈 상단의 현재 사용자 표시·로그아웃 행동
- 전체 학습자료·퀴즈 검색과 편집 UI
- 복습 대상 산정 알고리즘
- 경험치, 랭킹, 친구, 상점과 캐릭터 꾸미기

## 요구사항 구분

### 확정 사항

- 홈 상단의 `현재 사용자: …`와 `로그아웃`은 제거한다. 로그아웃은 [마이페이지 화면](screen-mypage.md)의 계정 관리에만 둔다.
- 헤더 아래에는 인증된 사용자의 닉네임을 사용한 짧은 환영 문구를 둔다.
- 방문일을 제공할 수 있으면 `연속 방문 {n}일째예요`처럼 의미를 문장에 직접 쓴다. 숫자 `0`을 데이터 없음의 대체값으로 표시하지 않는다.
- `오늘의 학습` 영역은 홈에서 제거한다.
- 최근 학습자료 `전체 보기`는 `학습 > 내 학습자료` 관리 목록으로 이동한다.
- 최근 학습자료 행 또는 카드의 본문·chevron을 선택하면 같은 하나의 링크로 해당 학습자료 관리 화면에 이동한다.
- 복습 카드의 주 제목은 학습자료명이나 `복습 이어서 풀기` 같은 행동명이 아니라 사용자가 식별하는 `퀴즈명`이다.
- 카드·행의 trailing chevron은 제목 첫 줄이 아니라 전체 인터랙티브 영역의 세로 중앙에 정렬한다.
- 홈의 첫 번째 강조 행동은 계속 사용자 상태에 맞는 대표 다음 학습 행동이다.
- `운영체제 중간고사 대비에서 다시 볼 문제가 4개 있어요`와 같은 대표 다음 행동 카드는 기존의 따뜻한 당근색 계열 인상을 복구한다.

### 설계 결정

- 환영 영역은 큰 hero 카드로 만들지 않는다. `👋` 같은 Unicode 이모지 한 개와 두 줄 이내 문구로 친근함만 더하고, 학습 행동보다 강한 장식·배경을 사용하지 않는다.
- 이모지는 장식 요소로 처리하며 접근 가능한 이름에는 포함하지 않는다. 플랫폼별 렌더링 차이를 허용하고 iOS 전용 이미지 자산에 의존하지 않는다.
- 환영 문구 기본안은 `👋 {nickname}님, 오늘도 반가워요`이고, 방문일 보조 문구는 `연속 방문 {n}일째예요`다.
- 닉네임만 불러오지 못하면 `오늘도 반가워요`를 표시한다. 방문일만 불러오지 못하면 방문일 문장을 숨기며 환영 영역 전체를 오류 상태로 바꾸지 않는다.
- 페이지가 짧을 때는 새 기능이나 통계를 만들지 않고 `새 문제 만들기`, `내 학습자료 관리` 두 기존 목적지를 약한 `빠른 시작` 목록으로 제공한다. 대표 행동과 목적지가 같으면 중복 행을 숨긴다.
- 대표 다음 행동만 quiet surface와 한 개의 prominent CTA를 사용한다. 복습·최근 자료·빠른 시작은 평평한 그룹형 목록과 여백으로 구분한다.
- 대표 다음 행동의 quiet surface는 하드코딩한 당근 palette 값이 아니라 SEED semantic `bg.brandWeak` 역할을 사용한다. 텍스트와 primary 행동의 대비는 SEED recipe를 따르며 색만으로 복습 상태를 전달하지 않는다.
- 퀴즈명이 길면 최대 두 줄까지 보이고 카드 높이가 늘어난다. 행동명은 `복습 시작` 또는 활성 세션이 있을 때 `이어서 풀기`로 별도 표시한다.
- 퀴즈명 변경 후 홈으로 돌아오면 변경된 이름이 표시되어야 한다. 이름 편집 동작 자체는 [학습 화면](screen-learning.md)의 퀴즈 관리 책임이다.

### 미결정 사항

- `연속 방문`을 로그인 성공, 홈 조회 또는 실제 학습 행동 중 무엇으로 기록할지와 날짜 경계·시간대
- 같은 날 여러 기기에서 방문했을 때의 중복 처리와 연속 방문이 끊긴 뒤의 초기값
- 같은 우선순위의 대표 다음 행동 후보가 여러 개일 때의 최종 동률 처리
- 여러 미완료 풀이가 있을 때 홈에서 대표 하나만 보여줄지 선택할 수 있게 할지
- 정확한 데스크톱 콘텐츠 최대 너비와 다크 모드 노출 정책

## 진입과 이탈

### 진입점

- 로그인 완료 후 기본 화면
- 하단 `홈` 탭
- 자료 관리, 문제 생성, 풀이 또는 결과에서 명시적으로 `홈으로`를 선택한 경우

### 이탈 목적지

| 홈 행동 | 이동 목적지 | 유지해야 할 맥락 |
| --- | --- | --- |
| 대표 `이어서 풀기` | 기존 풀이 세션 | QuizSet, attempt, 현재 문항과 저장된 답안 |
| 대표 또는 복습 카드의 `복습 시작` | 해당 퀴즈의 복습 풀이 | `quizSetId`, 원본 attempt 또는 활성 review session |
| 대표 `문제 만들기` | 해당 자료의 문제 생성 조건 | `materialId`, 자료명 |
| 복습 `전체 보기` | `학습 > 내 퀴즈 목록` | 홈에서 선택한 별도 필터가 있다면 유지 |
| 최근 학습자료 `전체 보기` | `학습 > 내 학습자료` | 기본 자료 관리 목록 상태 |
| 최근 학습자료 행 또는 chevron | 해당 학습자료 관리 | `materialId` |
| 빠른 시작 `새 문제 만들기` | 학습의 새 문제 만들기 | 없음 |
| 빠른 시작 `내 학습자료 관리` | `학습 > 내 학습자료` | 기본 자료 관리 목록 상태 |

chevron은 별도 목적지나 별도 포커스 대상이 아니다. 행의 어느 영역을 선택해도 표에 정의된 하나의 목적지로 이동한다.

## 모바일 우선 화면 구조

```text
홈
├─ 화면 헤더: 홈
├─ 환영 영역
│  ├─ 👋 {nickname}님, 오늘도 반가워요
│  └─ 연속 방문 {n}일째예요 (데이터가 있을 때만)
├─ 대표 다음 행동 quiet surface
│  ├─ 상태별 제목과 최소 맥락
│  └─ 대표 행동 1개
├─ 복습
│  ├─ 섹션 보조 행동: 전체 보기
│  └─ 퀴즈명 / 자료명·문항 수 / 복습 시작 또는 이어서 풀기
├─ 최근 학습자료
│  ├─ 섹션 보조 행동: 전체 보기
│  └─ 최근 자료 최대 3개
├─ 빠른 시작 (화면이 짧고 대표 행동과 중복되지 않을 때)
│  ├─ 새 문제 만들기
│  └─ 내 학습자료 관리
├─ 하단 콘텐츠 여백
└─ 홈·학습·마이페이지 하단 내비게이션
```

- 단일 세로 스크롤이며 DOM 순서와 시각 순서를 일치시킨다.
- `오늘의 학습`과 홈 상단 로그아웃은 어떤 상태에서도 삽입하지 않는다.
- 화면이 넓어져도 환영 문구와 대표 행동을 먼저 읽는 순서를 바꾸지 않는다.

## 영역별 콘텐츠와 행동

### 1. 화면 헤더와 환영 영역

| 상태 | 표시 |
| --- | --- |
| 닉네임·방문일 성공 | `👋 {nickname}님, 오늘도 반가워요` + `연속 방문 {n}일째예요` |
| 닉네임만 성공 | `👋 {nickname}님, 오늘도 반가워요` |
| 방문일만 성공 | `👋 오늘도 반가워요` + `연속 방문 {n}일째예요` |
| 둘 다 실패 | `오늘도 반가워요` |

- `홈`은 화면의 `h1`이다. 환영 문구는 lead text이며 계정 전환·로그아웃 컨트롤이 아니다.
- 방문일이 첫날이면 `1일째`로 표시한다. `0일째`, 음수, null을 사용자에게 그대로 노출하지 않는다.
- 방문일은 성취나 보상을 약속하지 않으며 이 값만으로 학습 완료를 표현하지 않는다.

### 2. 대표 다음 행동

정상 상태에서 한 개의 대표 행동만 보여준다. 상태별 제목이 접근 가능한 섹션 이름이 되고, 필요한 최소 맥락과 결과가 분명한 행동 레이블을 함께 둔다. 대표 행동 컨테이너는 상태별 문구가 바뀌어도 `bg.brandWeak`의 따뜻한 강조 surface를 유지하며 로딩·오류는 각각 중립 Skeleton과 semantic 오류 표현을 사용한다.

| 후보 상태 | 제목 예시 | 대표 행동 |
| --- | --- | --- |
| 미완료 풀이 | `{quizTitle}을 이어서 풀어보세요` | `이어서 풀기` |
| 복습 있음 | `{quizTitle}에서 다시 볼 문제가 {n}개 있어요` | `복습 시작` 또는 `이어서 풀기` |
| 문제 없는 자료 | `{materialTitle}으로 첫 문제를 만들어보세요` | `문제 만들기` |
| 최근 자료만 있음 | `{materialTitle}을 다시 살펴보세요` | `학습자료 관리` |
| 첫 방문 | `첫 학습자료를 만들고 문제를 풀어보세요` | `학습자료 만들기` |

- 우선순위 가정은 `미완료 풀이 → 복습 대상 → 문제가 없는 학습자료 → 최근 자료 → 첫 학습 시작`이다.
- `quizTitle`과 `materialTitle`은 서로 대체하지 않는다.
- 이동 중에는 로딩 상태와 중복 실행 방지를 함께 제공한다.

### 3. 복습

| 상태 | 표시 | 행동 |
| --- | --- | --- |
| 복습 대상 있음 | 주 제목 `quizTitle`, 보조 정보 `materialTitle`·복습 문항 수, 필요 시 마지막 활동 시각 | 카드 전체는 해당 퀴즈 복습, `전체 보기`는 내 퀴즈 목록 |
| 활성 복습 세션 있음 | 같은 퀴즈명과 남은 범위, 행동 레이블 `이어서 풀기` | 활성 session 재개 |
| 복습 없음 | `지금 복습할 문제는 없어요`와 새 문제 만들기를 권하는 짧은 문장 | 별도 prominent CTA 없음 |
| 불러오기 실패 | 이 영역만 불러오지 못했다는 설명 | `다시 시도` |

- 주 제목에 `복습 이어서 풀기`, `최근 완료한 퀴즈` 같은 일반 행동명을 쓰지 않는다.
- 퀴즈명이 존재하지 않는 계약 상태를 학습자료명으로 조용히 대체하지 않는다. 개발용 mock은 명시적인 `quizTitle`을 가진다.

### 4. 최근 학습자료

- 최근 수정 또는 활동 순서의 자료를 최대 3개 표시한다.
- 각 행은 자료명, 출처, 마지막 수정 시각처럼 관리 대상을 식별하는 정보만 담는다.
- 행 전체는 해당 자료의 제목·본문을 확인하고 수정할 수 있는 관리 화면으로 이동한다.
- `전체 보기`는 검색 가능한 `학습 > 내 학습자료` 목록으로 이동한다.
- 목록이 비면 별도 빈 카드 대신 대표 행동과 빠른 시작이 역할을 대신한다.

### 5. 빠른 시작

- 페이지가 짧을 때만 `새 문제 만들기`, `내 학습자료 관리`를 약한 그룹형 링크 행으로 제공한다.
- 이미 대표 행동과 같은 목적지인 항목은 숨겨 반복 선택지를 만들지 않는다.
- 새 통계, 추천 알고리즘, 장식 배너를 추가하지 않고 기존 학습 목적지만 재사용한다.

### 6. 인터랙티브 행과 chevron

- 카드·행 전체가 하나의 링크 또는 버튼이며 chevron만 따로 누르게 하지 않는다.
- trailing 영역은 텍스트 열과 별도 레이아웃 슬롯으로 구성한다. chevron은 전체 행의 상단·제목 baseline이 아니라 `align-self: center`와 동등한 방식으로 세로 중앙에 위치한다.
- 제목이 두 줄 이상이거나 보조 정보가 늘어나도 chevron은 전체 카드 높이의 중앙을 유지하고 텍스트와 겹치지 않는다.
- trailing 슬롯에는 최소한의 고정 여유를 두되 전체 터치 대상은 행 전체다.
- chevron은 장식으로 숨기고 링크의 접근 가능한 이름은 `퀴즈명, 복습 시작`, `자료명, 학습자료 관리`처럼 목적을 포함한다.
- hover, pressed, focus-visible을 구분하고 최소 44×44 CSS px 터치 영역을 확보한다.

## 상태

| 상태 | 사용자에게 보이는 결과 | 복구·다음 행동 |
| --- | --- | --- |
| 초기 로딩 | 환영, 대표 행동, 복습, 최근 자료의 최종 윤곽과 유사한 중립 Skeleton | 하단 탭은 유지 |
| 첫 방문 | 일반 환영 문구, 첫 자료 만들기 대표 행동, 중복되지 않는 빠른 시작 | `학습자료 만들기` |
| 부분 오류 | 성공한 영역은 유지하고 실패한 영역 안에 설명 | 영역별 `다시 시도` |
| 대표 판단 불완전 | 완전한 추천으로 표현하지 않는 안내 | 요약 재시도, 독립적인 빠른 시작 유지 |
| 전체 오류 | 홈 요약을 불러오지 못했다는 결과 영역 | 전체 재시도, 학습 탭과 마이페이지 탭 유지 |
| 세션 만료 | 개인 학습 정보 제거 후 인증 흐름 | 로그인 완료 뒤 홈 재진입 |

## 반응형·WebView

- `base`와 작은 WebView는 한 열, 세로 스크롤을 사용한다. 320 CSS px와 큰 글자에서도 가로 스크롤이 생기지 않는다.
- 긴 닉네임·퀴즈명·자료명은 줄바꿈하고 행 높이가 늘어난다. trailing chevron과 겹치지 않는다.
- `md` 이상에서도 같은 정보 순서와 한 개의 주요 읽기 열을 유지한다. 넓어진 공간은 바깥 여백에 사용한다.
- 앱 셸과 웹 중 한 계층만 safe-area를 소유한다. 마지막 빠른 시작 행과 최근 자료가 하단 내비게이션에 가리지 않게 콘텐츠 여백을 둔다.
- 하단 내비게이션에는 텍스트 레이블과 보조 아이콘을 함께 두고 현재 홈을 색 외의 상태로 전달한다.
- 홈을 포함한 최상위 탭 전환은 [제품 기반의 최상위 탭 전환 모션](../product.md#최상위-탭-전환-모션)을 따른다. 학습·마이페이지에서 홈으로 돌아올 때도 동일하게 목적지 콘텐츠가 오른쪽에서 들어오고 기존 콘텐츠가 왼쪽으로 물러난다.

## 접근성

- `홈`은 하나의 `h1`, 대표 행동·복습·최근 자료·빠른 시작은 순서에 맞는 하위 제목을 사용한다.
- 장식 이모지와 chevron은 중복 낭독하지 않는다.
- 환영 문구의 숫자는 `연속 방문 7일째`처럼 단위와 의미를 함께 읽을 수 있어야 한다.
- 행 전체가 한 번의 탭 정지점이며 내부에 중첩 링크나 버튼을 두지 않는다.
- 키보드 포커스 링을 유지하고 긴 텍스트와 글자 확대 시 콘텐츠를 자르지 않는다.
- 로딩·오류·복습 문항 수는 색이나 아이콘만으로 전달하지 않는다.

## SEED 컴포넌트 역할 후보

정확한 props·import와 아이콘 이름은 구현 단계에서 현재 설치 버전과 SEED Docs로 다시 검증한다.

| UI 책임 | 후보 | 사용 원칙 |
| --- | --- | --- |
| 화면·섹션 배치 | `Box`, `VStack`, 필요한 짧은 행의 `HStack`/`Flex`, `Text` | 단일 읽기 열과 의미 있는 heading 순서를 유지 |
| 대표 행동 | `ActionButton` | 한 개의 prominent solid CTA만 사용 |
| 복습·최근 자료·빠른 시작 | `List`, `ListButtonItem` 또는 `ListLinkItem`, 필요 시 `ListDivider` | 전체 행 한 행동, trailing chevron은 장식 |
| 로딩 | 중립 `Skeleton` | AI 생성이 아니므로 magic 표현을 사용하지 않음 |
| 영역·전체 오류 | `ResultSection`, 필요 시 `PageBanner` | 설명과 재시도 행동을 인접하게 제공 |
| 짧은 재시도 성공 | `Snackbar` | 영구 상태나 오류 설명을 대신하지 않음 |

## 필요한 데이터·계약 영향

### 기존 계약으로 사용할 수 있는 값

- 현재 사용자 `GET /api/v1/users/me`의 `nickname`
- 학습자료 식별자·제목·출처·수정 시각
- 복습의 QuizSet·attempt·review session 식별자와 복습 문항 수

### API 계약에 추가하거나 의미를 확정해야 하는 값

| 필요 값 | 이유 | 계약 원장 |
| --- | --- | --- |
| 비어 있지 않은 `quizTitle` | 홈 복습 카드와 대표 행동을 학습자료명이 아닌 퀴즈명으로 식별 | [학습·퀴즈 API](../contracts/contract-api-quiz-learning.md)와 [학습자료·퀴즈 데이터](../contracts/contract-data-quiz-learning.md) |
| 퀴즈명 변경 결과와 최신 조회 반영 | 학습의 퀴즈 관리에서 바꾼 제목을 홈·목록·풀이가 같은 의미로 표시 | 같은 퀴즈 계약 원장 |
| 연속 방문일과 기준 사건 | 환영 영역의 방문일 문구 | [홈 방문 API 목표 계약](../contracts/contract-api-home.md) |

- `quizTitle`이 없는 현재 복습 응답의 `materialTitle`을 퀴즈명처럼 표시하지 않는다.
- 방문일 계약이 준비되기 전에도 닉네임 환영 문구와 나머지 홈 기능은 동작해야 한다.
- 정확한 endpoint·필드명·캐시 정책은 이 화면 문서가 아니라 위 계약 원장이 책임진다.

## 관찰 가능한 수용 기준

- [ ] 홈 상단에 `현재 사용자`와 `로그아웃` 컨트롤이 없고, 로그아웃은 마이페이지에서 접근한다.
- [ ] 사용자 정보가 있으면 닉네임 환영 문구가 보이며 방문일이 없거나 실패해도 `0일째`로 표시되지 않는다.
- [ ] 홈 어디에도 `오늘의 학습` 영역이 없다.
- [ ] 정상 상태의 홈에는 prominent 대표 행동이 정확히 한 개다.
- [ ] `운영체제 중간고사 대비에서 다시 볼 문제가 4개 있어요` 상태를 포함한 대표 다음 행동 카드가 semantic `bg.brandWeak` 역할의 따뜻한 배경을 사용하고, 다른 일반 목록 카드에는 같은 강조 배경을 확산하지 않는다.
- [ ] 복습 카드의 주 제목은 `quizTitle`이며 학습자료명과 행동명은 보조 정보·행동으로 분리된다.
- [ ] 복습 `전체 보기`는 내 퀴즈 목록, 최근 학습자료 `전체 보기`는 내 학습자료 목록으로 이동한다.
- [ ] 최근 학습자료 행의 어느 곳을 선택해도 해당 자료 관리 화면으로 이동한다.
- [ ] 모든 trailing chevron은 제목 줄이 아니라 전체 카드·행 높이의 세로 중앙에 있고 별도 포커스 대상이 아니다.
- [ ] 페이지가 짧으면 기존 기능만 사용하는 빠른 시작이 보이며 대표 행동과 같은 목적지는 중복되지 않는다.
- [ ] 로딩·빈 상태·부분 오류에서도 성공한 영역과 하단 내비게이션은 사용할 수 있다.
- [ ] 320 CSS px, 긴 한국어 제목과 큰 글자에서 텍스트·chevron이 겹치거나 가로 스크롤이 생기지 않는다.
- [ ] 학습·마이페이지에서 홈 탭을 선택하면 전역 탭 모션 규칙과 같은 방향의 전환이 항상 보이고, reduced motion에서는 위치 이동 없는 대체가 적용된다.
- [ ] 홈 재진입 애니메이션이 홈의 스크롤·화면 상태·유효한 서버 캐시를 초기화하거나 같은 API를 불필요하게 다시 요청하지 않는다.

## 사용자 검토가 필요한 결정

1. `연속 방문`의 기준 사건과 날짜 경계를 어떤 정책으로 집계할지
2. 복습 `전체 보기`의 초기 상태를 전체 퀴즈 목록으로 둘지, 복습 대상 필터가 적용된 퀴즈 목록으로 둘지
3. 여러 미완료 풀이가 있을 때 대표 하나만 노출할지 선택 UI를 제공할지
