# [Screen Spec] 프로필

## 문서 정보

- 문서 상태: `draft`
- 요구사항 상태: 하단 영역과 자체 로그인 우선 원칙은 확인됨, 상세 설정은 미확정
- 대상 플랫폼: 모바일 WebView 우선

## 확정 사항

- 최상위 하단 내비게이션의 세 번째 영역은 `프로필`이다.
- 초기 배포는 자체 로그인으로 시작하고 소셜 로그인은 앱 배포 이후로 미룬다.
- 경험치·레벨·랭킹, 친구, 상점·포인트와 캐릭터·방 꾸미기는 이후 확장 후보이다.

## 설계 가정

- MVP 프로필은 계정 식별 정보와 개인 설정으로 들어가는 허브 역할을 한다.
- 로그아웃처럼 계정 세션에 영향을 주는 행동은 일반 설정과 분리한다.
- 아직 사용할 수 없는 게임화·친구 기능은 잠금 카드로 과도하게 노출하지 않고, 실제 출시 범위가 정해진 뒤 추가한다.

## 미결정 사항

- 사용자명·프로필 이미지의 제공 및 편집 범위
- 알림, 학습 기본값, 테마 등 초기 설정 항목
- 비밀번호 변경·재설정과 계정 탈퇴 흐름
- 경험치가 도입될 때 프로필과 랭킹 중 어느 곳을 대표 노출로 삼을지
- 설정을 프로필 내부 목록으로 둘지 별도 하위 화면으로 분리할지

## 제안 정보 구조

1. 화면 제목과 최소 계정 정보
2. 계정 관리
3. 학습 기본 설정
4. 앱·서비스 정보와 고객 지원
5. 로그아웃 및 계정 관련 위험 행동
6. `홈`, `학습`, `프로필` 하단 내비게이션

## 필수 상태

- 프로필 불러오는 중
- 정상 계정
- 일부 설정 불러오기 실패
- 세션 만료
- 설정 저장 중, 성공, 실패
- 로그아웃 확인과 처리 실패

## 접근성·WebView 기준

- 설정 행의 현재 값과 변경 가능 여부를 레이블로 전달한다.
- 로그아웃과 계정 탈퇴 같은 행동은 위치·색상·확인 단계로 일반 행동과 구분한다.
- 저장 성공·실패 피드백은 보조기기에 전달하고 실패 시 입력을 유지한다.
- 하단 탭의 현재 위치와 안전 영역을 보존한다.

## 비범위

- 소셜 로그인 구현
- 랭킹, 친구 관계, 포인트 경제와 캐릭터 꾸미기의 상세 정책·화면
