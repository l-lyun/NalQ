# 제품 결정 기록

되돌아볼 가치가 있는 제품 결정을 한 파일씩 기록한다. 단순 회의 메모나 아직 선택하지 않은 아이디어 목록으로 사용하지 않는다.

## 파일명

`YYYY-MM-DD-short-title.md`

## 필수 내용

- 상태: 제안 / 확정 / 대체됨
- 결정일과 참여자
- 맥락과 해결할 문제
- 검토한 선택지
- 결정과 이유
- 사용자 경험 및 구현 영역에 미치는 영향
- 대체된 경우 새 결정 문서 링크

## 현재 대화에서 확인된 결정

초기 제품 문서에는 다음 결정을 직접 반영했다. 별도 결정 기록은 상세한 대안과 이유가 추가로 합의될 때 만든다.

- 초기 하단 탭은 홈, 학습, 프로필 세 개다.
- 학습과 문제 만들기를 하나의 상위 영역으로 묶는다.
- 학습자료와 복습을 별도 하단 탭으로 나누지 않는다.
- 설정은 독립 하단 탭보다 프로필 안에서 제공한다.
- 소셜 로그인은 앱 배포 이후로 미룬다.
- 작업은 자동 에이전트 파이프라인이 아니라 사람의 검토를 사이에 둔 짧은 전문 작업으로 진행한다.
