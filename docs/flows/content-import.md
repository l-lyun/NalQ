# 사용자 흐름: 학습자료 가져오기

- 상태: 초안
- 관련 기능: [학습자료 가져오기](../features/02-content-import.md)

## 시작 조건

- 로그인한 사용자가 홈의 새 학습 또는 학습 탭의 자료 추가를 선택한다.

## 공통 흐름

1. 사용자가 Notion, 파일, 붙여넣기 중 하나를 선택한다.
2. 입력 방식별로 원문을 선택하거나 제공한다.
3. 시스템이 지원 여부와 내용 유효성을 확인하고 텍스트를 준비한다.
4. 사용자가 제목과 문제 생성에 사용할 본문을 확인한다.
5. 사용자가 확정하면 시스템이 학습자료를 저장한다.
6. 사용자는 바로 문제를 만들거나 자료 상세로 이동한다.

## Notion 분기

1. 연결되지 않았다면 사용자가 Notion 접근을 승인한다.
2. 시스템은 허용된 범위에서 선택 가능한 콘텐츠를 보여준다.
3. 사용자가 하나의 글을 선택한다.
4. 시스템이 콘텐츠를 가져와 공통 확인 단계로 보낸다.

연결 취소, 권한 없음, 접근 철회, 지원하지 않는 블록은 서로 구분 가능한 복구 안내를 제공한다.

## 파일 분기

1. 사용자가 기기에서 파일을 선택한다.
2. 시스템이 확장자, 크기, 읽기 가능 여부를 확인한다.
3. `.txt` 또는 `.md`의 본문을 추출해 공통 확인 단계로 보낸다.

지원하지 않는 파일은 학습자료를 만들지 않고 허용 형식을 안내한다.

## 붙여넣기 분기

1. 사용자가 입력창에 텍스트를 붙여넣고 필요하면 수정한다.
2. 시스템이 빈 내용과 허용 범위를 확인한다.
3. 유효한 내용을 공통 확인 단계로 보낸다.

## 취소와 실패

- 최종 확정 전 취소하면 학습자료를 생성하지 않는다.
- 처리 실패 후에는 사용자의 원입력을 가능한 범위에서 보존한다.
- 중복 제출로 같은 자료가 여러 번 생성되지 않게 한다.

## 열린 질문

- 확인 단계에서 본문 전체 편집을 허용할지
- 저장과 문제 생성 요청을 하나의 행동으로 묶을지
- Notion 콘텐츠 선택 화면의 검색·계층 표현 방식
