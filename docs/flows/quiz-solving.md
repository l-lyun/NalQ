# 사용자 흐름: 퀴즈 생성부터 복습까지

- 상태: 검토 중
- 관련 기능: [퀴즈 생성·풀이·결과·복습](../features/03-quiz-generation.md)
- 공유 계약: [학습자료·퀴즈 API 계약](../contracts/api/quiz-learning.md)
- 클라이언트 구현 원장: [웹 임시 상태·보존](../../web/docs/technical/quiz-solving.md), [앱 임시 상태·보존](../../app/docs/technical/quiz-solving.md)

## 문서 책임

이 문서는 화면과 상태 사이의 순서, 분기, 중단, 재개와 실패 복구를 정의한다. 문제 품질·채점·복습 대상 정책은 기능명세가, 요청·응답과 오류 코드는 API 계약이 책임진다.

## 사용자 목표

학습자료로 만든 퀴즈를 중단이나 실패에도 진행 상태를 이해하며 끝까지 풀고, 결과에서 필요한 문항을 복습한다.

## 시작 조건

- 로그인한 사용자가 자신이 소유한 유효한 학습자료를 선택했다.
- 학습자료 본문이 비어 있지 않고 20,000자를 넘지 않는다.
- 생성·평가 규칙은 [기능명세의 확정 정책](../features/03-quiz-generation.md#확정-정책)을 따른다.

## 완료 조건

- 본 퀴즈: 자동 채점과 필요한 서술형 자기평가가 끝나 완료 결과를 볼 수 있다.
- 복습: 현재 세션의 모든 대상 문항을 한 번씩 평가해 해결·미해결 상태가 저장된다.

## 기본 흐름

### A. 생성

1. 사용자가 문제 유형을 하나 이상 선택하고 난이도와 최대 문제 수를 정한다.
2. 사용자가 생성을 요청하면 시스템은 요청을 접수하고 즉시 학습자료 본문을 잠근다.
3. 차단형 생성 오버레이가 열리고 완료 여부를 알 수 없는 진행 표시를 보여준다.
4. 클라이언트는 3초 뒤 처음 상태를 확인하고, 이후 5초 간격으로 확인한다. 생성 시작 후 2분이 지나면 10초 간격으로 낮춘다.
5. 성공하면 실제 생성 문제 수와 조건을 보여주고 본 퀴즈 시작 행동을 제공한다.
6. 실패하면 불완전한 문제를 노출하지 않고 기존 생성 조건을 유지한 채 재시도를 제공한다.

### B. 본 퀴즈 풀이와 제출

1. 사용자가 본 퀴즈를 시작하면 첫 문항을 보여준다.
2. 사용자는 답을 작성하고 이전·다음으로 이동한다. 이동만으로 채점하지 않는다.
3. 풀이 중 현재 위치와 답안은 같은 기기에 임시 보존된다.
4. 제출을 선택했을 때 미응답이 있으면 `남은 문제 풀기`와 `그대로 제출`을 제공한다.
5. `남은 문제 풀기`를 선택하면 번호가 가장 낮은 미응답 문항으로 이동한다.
6. `그대로 제출` 또는 모든 문항 응답 후 제출하면 최종 제출을 한 번 접수하고 본 퀴즈 회차를 만든다.
7. 자동 채점 뒤 작성한 서술형이 있으면 자기평가 흐름으로, 없으면 결과로 이동한다. 미응답 서술형은 자기평가 없이 오답 처리한다.

### C. 서술형 자기평가

1. 첫 서술형에서는 자기평가 방식과 자동 점수 제외를 안내한다.
2. 사용자는 내 답과 모범 답안·핵심 포인트·해설·원문 근거를 비교한다.
3. 사용자는 `정답`, `부분 이해`, `오답` 중 하나를 선택해 저장한다.
4. 다음 미평가 서술형으로 이동한다.
5. 마지막 평가가 저장되면 본 퀴즈 회차가 완료되고 결과로 이동한다.

### D. 결과

1. 시스템은 자동 채점 요약, 서술형 자기평가 요약과 복습할 문제 수를 보여준다.
2. 그 아래에 모든 문항을 번호 오름차순으로 보여준다.
3. 사용자가 한 문항을 선택하면 결과 읽기 모드에서 내 답, 정답 또는 모범 답안, 판정, 해설과 원문 근거를 확인한다.
4. 사용자는 결과 목록으로 돌아오거나 학습 영역의 복습으로 이동한다.

### E. 복습

1. 복습 탭 진입 시 시스템은 가장 최근 완료한 본 퀴즈 회차의 미해결 문항 수와 활성 복습 세션을 확인한다.
2. 활성 세션이 있으면 그 세션의 다음 미처리 문항으로 재개한다.
3. 활성 세션 없이 대상이 있으면 최신 완료 회차를 원본으로 서버 복습 세션을 만들고 원래 번호 오름차순 첫 문항을 보여준다.
4. 사용자가 답을 제출하면 즉시 저장하고 자동 채점 가능한 유형은 바로 판정한다.
5. 서술형은 답 작성 후 모범 답안·핵심 포인트·근거를 보고 자기평가한다.
6. `정답`은 해결, 그 밖의 판정은 미해결로 저장하고 같은 세션에서 재출제하지 않은 채 다음 문항으로 이동한다.
7. 마지막 문항 판정 뒤 이번 복습의 해결·미해결 요약을 보여준다. 원래 본 퀴즈 결과는 바꾸지 않는다.

## 분기

### 생성 화면에서 나가기

1. 사용자가 생성 중 뒤로가기를 하면 시스템은 생성이 서버에서 계속됨을 알리는 이탈 확인을 연다.
2. 머물기를 선택하면 오버레이로 돌아간다.
3. 나가기를 선택하면 이전 화면으로 이동하고 서버 생성은 계속된다.
4. 같은 자료에 다시 진입하면 [자료의 활성 생성 조회](../contracts/api/quiz-learning.md#자료의-활성-생성-조회)로 `GENERATING` QuizSet을 재발견한다.
5. 활성 QuizSet이 있으면 그 `quizSetId`의 상태 조회를 재개하고, 없을 때만 새 생성 가능 상태를 보여준다.

### 본 퀴즈 재진입

1. 같은 계정과 문제 세트의 7일 이내 기기 임시 기록이 있으면 `이어서 풀기`와 `처음부터`를 제공한다.
2. 이어서 풀기는 저장된 문항 위치와 답을 복원한다.
3. 처음부터는 해당 임시 기록을 초기화하고 첫 문항으로 이동한다.
4. 임시 기록이 만료됐거나 다른 기기라면 첫 문항부터 시작한다. 서버 기록으로 복원된 것처럼 안내하지 않는다.

### 서술형 자기평가 재진입

1. 최종 제출 뒤 자기평가를 끝내기 전에 이탈했다면 [미완료 서술형 자기평가 회차 조회](../contracts/api/quiz-learning.md#미완료-서술형-자기평가-회차-조회)로 이미 생성된 `attemptId`와 남은 서술형 문항을 찾는다.
2. 복원 대상이 있으면 문제 번호가 가장 낮은 미평가 서술형부터 자기평가 화면을 복원한다.
3. 복원 대상이 없으면 현재 attempt와 결과 상태 또는 본 퀴즈 시작 가능 상태를 다시 확인한다.

### 복습 서술형 자기평가 재진입

1. 복습 세션 조회에서 문항이 `SELF_ASSESSMENT_REQUIRED`이면 저장된 답·모범 답안·핵심 포인트·해설·원문 근거로 해당 자기평가 화면을 복원한다.
2. 그 서술형 자기평가를 저장하기 전에는 다른 복습 문항으로 건너뛰지 않는다.

### 복습 대상 없음

1. 최근 완료한 본 퀴즈가 없거나 최신 회차의 복습할 문제 수가 0이면 빈 상태를 보여준다.
2. 새 본 퀴즈를 시작하거나 학습자료로 돌아가는 행동을 제공한다.

## 중단과 재개

- 생성 상태 조회는 첫 3초 후, 이후 5초마다, 2분 뒤부터 10초마다 수행한다. 화면 이탈 시 조회만 중단하며 서버 생성을 취소하지 않는다.
- 본 퀴즈 최종 제출 전 상태는 계정과 문제 세트 조합별로 기기에 7일간만 보존한다. 서버는 이를 이어 풀기 데이터로 제공하지 않는다.
- 최종 제출 뒤 생성된 attempt 상태 또는 결과 조회 성공을 확인하면 해당 기기 임시 기록을 제거한다. 응답 유실 여부가 해결되기 전에는 먼저 제거하지 않는다.
- 서술형 자기평가와 복습은 서버 상태를 기준으로 다음 미완료 문항을 복원한다.
- 로그아웃하면 해당 시점의 현재 사용자에게 속한 모든 미제출 로컬 퀴즈 기록을 즉시 삭제한다. 다른 사용자 키를 함께 삭제하거나 로그아웃 뒤 이전 사용자의 기록을 복원하지 않는다.

## 열린 질문

- 없음. 이번 MVP의 분기·중단·복구 순서는 위 흐름을 기준으로 한다.
