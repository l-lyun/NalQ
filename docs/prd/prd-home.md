# [PRD] 홈

- 상태: 초안
- 관련 원장: [제품 기반의 전역 내비게이션](../product.md#전역-내비게이션)

## 사용자 문제

사용자는 앱을 열었을 때 자료 목록과 여러 기능 사이에서 무엇을 먼저 해야 할지 판단해야 한다. 이전 학습 맥락을 기억하지 못하면 학습을 재개하기 어렵다.

## 목표

사용자가 홈에서 현재 가장 가치 있는 학습 행동을 이해하고 한 번의 선택으로 시작하게 한다.

## 범위

- 사용자 상태에 맞는 대표 다음 행동 한 개
- 닉네임 기반 환영 문구와 연속 방문일 보조 문구
- 새 학습 시작 진입점
- 필요한 복습의 요약과 진입점
- 최근 학습자료
- 학습 이력이 적을 때 기존 기능으로 구성한 빠른 시작
- 데이터가 없는 첫 사용자 상태와 각 섹션의 빈 상태

## 비범위

- 전체 학습자료 관리
- 상세 통계와 계정 설정
- `오늘의 학습` 통계와 날짜별 집계
- 경험치, 랭킹, 친구, 꾸미기의 초기 구현

## 핵심 규칙

- 홈의 첫 번째 강조 요소는 기능 목록이 아니라 `다음 학습 행동`이다.
- 다음 행동 후보의 제안 우선순위는 [제품 기반의 전역 내비게이션](../product.md#전역-내비게이션)의 초안을 따른다.
- 복습과 학습자료는 홈에서 요약만 제공하고 상세 탐색은 학습 탭으로 연결한다.
- 홈 상단에는 현재 사용자 표시나 로그아웃을 두지 않고 닉네임 환영 문구만 제공한다. 로그아웃은 마이페이지에서 수행한다.
- 복습 항목의 식별 제목은 학습자료명이나 행동명이 아니라 퀴즈명이다.
- 최근 학습자료 `전체 보기`는 학습자료 관리 목록, 개별 항목은 해당 자료 관리 화면으로 연결한다.
- `오늘의 학습`은 표시하지 않는다.
- 새 사용자는 빈 카드 여러 개 대신 학습자료 가져오기를 시작하도록 안내한다.
- 불러오기 실패 등 일부 데이터가 없더라도 가능한 다른 홈 행동은 사용할 수 있어야 한다.

## 주요 상태

| 상태 | 기대 동작 |
| --- | --- |
| 첫 방문 | 자료를 가져오는 첫 행동과 지원 입력 방식을 설명한다. |
| 미완료 풀이 있음 | 이어 풀기를 대표 행동으로 제안한다. |
| 복습 대상 있음 | 복습할 규모와 시작 행동을 보여준다. |
| 문제 없는 자료 있음 | 해당 자료로 문제 만들기를 제안한다. |
| 최근 학습만 있음 | 최근 자료를 다시 열 수 있다. |
| 홈 데이터 로딩 실패 | 재시도와 가능한 독립 행동을 제공한다. |

## 수용 기준

- 로그인한 사용자는 홈에서 홈·학습·마이페이지 탭을 식별하고 이동할 수 있다.
- 사용자의 학습 상태가 하나 이상이면 홈은 대표 다음 행동을 하나 보여준다.
- 대표 행동을 선택하면 해당 자료 또는 풀이 맥락이 유지된 다음 단계로 이동한다.
- 학습 이력이 없는 사용자는 지원되는 방식으로 자료를 가져오는 흐름을 시작할 수 있다.
- 복습 요약에서 복습 풀이로, 최근 자료에서 해당 자료 상세로 이동할 수 있다.
- 복습 항목에는 퀴즈명이 주 제목으로 표시되고, 퀴즈명 변경 후 홈에도 변경된 이름이 표시된다.
- 최근 자료 `전체 보기`는 검색 가능한 학습자료 관리 목록으로, 개별 자료는 해당 자료 관리 화면으로 이동한다.
- 방문일을 불러오지 못했을 때 `0일째`로 대체하지 않고 나머지 환영 문구와 홈 기능을 유지한다.
- 부분 오류가 발생했을 때 오류 원인 또는 재시도 행동을 알 수 있다.

## 열린 질문

- 연속 방문일을 기록하는 사건, 날짜 경계와 여러 기기 중복 처리
- 복습 대상을 결정하는 규칙
- 여러 미완료 풀이가 있을 때 대표 항목을 정하는 기준
- 홈에서 자료 가져오기 방식 선택을 바로 노출할지 학습 탭으로 이동할지

## 계약 영향

- 현재 사용자 닉네임은 기존 사용자 계약을 사용한다.
- 연속 방문일의 목표 endpoint와 날짜·멱등성 규칙은 [홈 방문 API 계약](../contracts/contract-api-home.md)에 기록하며, 구현 전까지 숫자 문구를 숨긴다.
- 복습 요약과 퀴즈 목록은 비어 있지 않은 `quizTitle`을 제공해야 하며, 학습자료명으로 대신하지 않는다.
- 퀴즈명 변경 결과가 홈·퀴즈 목록·풀이 화면에 같은 의미로 반영되도록 학습·퀴즈 API 및 데이터 계약을 갱신해야 한다.
