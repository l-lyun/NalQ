# 기능명세: 학습자료 가져오기

- 상태: 초안
- 관련 흐름: [자료 가져오기 흐름](../flows/content-import.md)

## 사용자 문제

사용자의 글은 Notion, 로컬 파일, 클립보드 등 서로 다른 곳에 있다. 출처마다 복잡한 준비를 요구하면 문제 풀이를 시작하기 전에 이탈한다.

## 목표

세 가지 입력 방식 중 편한 방법으로 글을 가져오고, 문제 생성에 사용할 내용을 확인하게 한다.

## 범위

- Notion 연결 후 접근 가능한 글 선택 및 가져오기
- `.txt`, `.md` 파일 업로드
- 입력창에 텍스트 붙여넣기
- 가져온 제목과 본문 미리 확인
- 지원하지 않는 입력, 빈 내용, 처리 실패 안내와 재시도

## 비범위

- PDF, 이미지 OCR, 웹 URL 자동 수집
- Notion 이외의 외부 문서 서비스
- 자동 동기화 및 충돌 해결 정책이 확정되기 전의 양방향 동기화

## 공통 규칙

- 출처와 관계없이 가져온 결과는 하나의 `학습자료`로 취급한다.
- 문제를 만들기 전에 사용자가 대상 본문과 제목을 확인할 수 있어야 한다.
- 빈 텍스트 또는 문제를 만들 근거가 부족한 텍스트는 저장·생성 단계 전에 안내한다.
- 원문을 일부 변환하거나 제외했다면 사용자가 알 수 있게 한다.
- 실패해도 사용자가 입력을 가능한 범위에서 잃지 않고 다시 시도할 수 있어야 한다.

## 입력별 규칙

### Notion

- 사용자가 허용한 범위의 콘텐츠만 보여주고 가져온다.
- 연결 취소, 권한 없음, 접근이 철회된 상태를 구분해 안내한다.
- 가져오기와 지속 동기화를 같은 의미로 약속하지 않는다.

### 파일

- `.txt`와 `.md`만 초기 지원 형식으로 안내한다.
- 지원하지 않는 형식과 읽을 수 없는 파일은 처리 전에 명확히 알린다.
- Markdown 문법을 문제의 사실 근거로 오해하지 않도록 본문 텍스트를 추출한다.

### 붙여넣기

- 사용자가 붙여넣은 텍스트를 검토하고 수정한 뒤 진행할 수 있게 한다.
- 공백뿐인 입력은 제출할 수 없다.

## 수용 기준

- 사용자는 세 입력 방식 중 하나를 선택할 수 있다.
- 각 지원 방식으로 유효한 본문을 가져오면 제목과 본문을 확인할 수 있다.
- 지원하지 않는 파일, 빈 입력, Notion 권한 실패에서 해결 가능한 다음 행동을 받는다.
- 확인한 자료를 저장하고 해당 자료의 문제 생성 단계로 이동할 수 있다.
- 사용자가 취소하면 의도하지 않은 학습자료나 문제 세트가 만들어지지 않는다.

## 열린 질문

- 파일 크기, 글자 수, Notion 블록 유형의 지원 한도
- 제목을 자동 추출하는 규칙과 중복 자료 처리
- Notion을 일회성 가져오기로 시작할지 수동 새로고침까지 제공할지
- 코드 블록, 표, 이미지 캡션, 링크 텍스트의 변환 정책
- 가져온 원문의 편집 허용 범위와 원본 출처 표시
