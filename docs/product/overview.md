# 제품 개요

- 상태: 초안
- 최종 갱신: 2026-08-19

## 한 문장 정의

OpenMD는 사용자가 가진 글을 학습자료로 가져와 AI가 만든 퀴즈로 풀고, 자신의 이해도를 확인하도록 돕는 학습 앱이다.

## 해결하려는 문제

글을 읽는 것만으로는 이해했는지 확인하기 어렵고, 직접 문제를 만드는 데 시간이 든다. OpenMD는 기존 지식 자료를 다시 입력하는 부담을 낮추고, 읽기에서 회상과 피드백으로 이어지는 짧은 학습 루프를 만든다.

## 핵심 사용자 여정

1. 사용자가 자체 계정으로 로그인한다.
2. Notion, 텍스트/Markdown 파일, 복사하여 붙여넣기 중 하나로 글을 가져온다.
3. 문제 유형과 난이도 등 생성 조건을 선택한다.
4. OpenAI 기반으로 생성된 문제를 푼다.
5. 채점 결과와 설명을 확인하고 필요한 내용을 다시 학습한다.

## 확정된 초기 범위

- 자체 회원가입과 로그인. 소셜 로그인은 앱 배포 이후로 미룬다.
- 세 가지 학습자료 입력: Notion 연결, `.txt`/`.md` 업로드, 텍스트 붙여넣기
- 네 가지 문제 풀이 방식: 객관식, 단답형, 주관식, 혼합형
- 난이도 조절
- OpenAI LLM API를 이용한 문제 생성 및 채점
- 하단 탭 세 개: 홈, 학습, 프로필
- 학습자료와 복습을 별도 하단 탭으로 분리하지 않고 학습 안에서 다룬다.
- 학습과 문제 만들기도 하나의 학습 흐름에서 이어지게 한다.

## 이후 확장 후보

아래 항목은 제품 방향에는 포함되지만 초기 출시 범위와 상세 정책은 아직 확정하지 않는다.

- 문제 풀이 경험치와 레벨
- 레벨 또는 성과 기반 랭킹
- 친구 맺기와 친구가 만든 문제 풀기
- 상점과 포인트
- 도트 또는 간결한 캐릭터, 프로필, 방 꾸미기

## 비범위

- 초기 배포 전 소셜 로그인
- 확정되지 않은 게임 경제, 랭킹 산식, 친구 공개 범위를 선행 구현하는 것
- 원문에 근거하지 않는 일반 지식 시험을 핵심 기능으로 삼는 것

## 성공의 초기 정의

- 사용자가 지원되는 방법 중 하나로 자료를 가져와 첫 퀴즈를 완주할 수 있다.
- 사용자가 정답 여부뿐 아니라 무엇을 다시 확인해야 하는지 이해할 수 있다.
- 다시 방문한 사용자가 중단한 학습 또는 필요한 복습을 빠르게 찾을 수 있다.

구체적인 지표와 목표치는 실제 사용 데이터를 수집하기 전에 별도로 합의한다.

## 열린 질문

- 1차 배포 플랫폼과 화면 크기 범위
- 대상 사용자의 우선순위: 학생, 직장인, 자격시험 학습자 등
- 무료 사용량, 결제, LLM 비용 제한 정책
- 자료와 생성 문제의 보관 기간 및 삭제 정책
- 복습 시점 추천 규칙과 학습 완료의 정의
