# [PRD] 학습자료 만들기

- 관련 흐름: [학습자료 만들기 흐름](../ux/flow-content-import.md)
- 공유 계약: [학습자료·퀴즈 API 계약](../contracts/contract-api-quiz-learning.md)

## 문서 책임

이 문서는 붙여넣기와 Notion 일회성 복사로 학습자료를 만드는 제품 정책을 정의한다. 화면 순서와 실패 복구는 관련 흐름이, HTTP 입출력·권한·오류는 공유 계약이 책임진다.

## 사용자 문제

사용자는 학습할 글을 빠르게 준비하고 싶지만, 가져오기 작업·임시 초안·동기화 같은 중간 개념이 많으면 퀴즈를 만들기 전에 이탈한다. 외부 문서가 자동으로 바뀔 것처럼 보이면 어떤 본문이 퀴즈의 근거인지도 불명확해진다.

## 목표

사용자가 붙여넣거나 Notion에서 선택한 한 페이지를 프론트에서 확인·수정한 뒤 하나의 저장 행동으로 학습자료를 만들고, 저장한 자료를 목록에서 찾아 상세 내용을 확인할 수 있다.

## 범위

- 일반 텍스트 붙여넣기와 프론트 편집
- 사용자가 선택한 Notion 단일 페이지의 일회성 복사
- 사용자별 Notion Public OAuth 연결, 접근 가능한 페이지 탐색과 단일 페이지 선택
- 복사한 Notion 제목과 Markdown 본문의 프론트 확인과 수정
- 제목과 최대 20,000자 본문을 학습자료로 저장
- 저장한 학습자료의 최근 수정 순 목록, 제목 검색과 페이지 이동
- 선택한 학습자료의 제목·본문·출처·수정 시각과 현재 본문 편집 가능 상태 확인
- 진행 중인 퀴즈 생성이 없을 때의 본문 편집과 항상 가능한 제목 편집

## 비범위

- `.txt`, `.md`를 포함한 로컬 파일 업로드
- Notion 자동 동기화, 수동 새로고침과 충돌 해결
- 서버 import job, `importId`, 서버 preview·draft와 임시 만료
- PDF, 이미지 OCR, 웹 URL 자동 수집
- Notion 이외의 외부 문서 서비스

## 확정 정책

### 공통

- 출처와 관계없이 저장 결과는 하나의 `학습자료`다.
- 제목은 필수이며 미입력·공백뿐인 제목에 기본 제목을 자동 적용하지 않는다.
- 본문은 공백 제외 여부와 관계없이 저장 시 유효한 텍스트가 있어야 하고 최대 20,000자다.
- 사용자는 저장 전에 프론트에서 제목과 본문을 확인하고 수정할 수 있다.
- 저장 전 취소하면 학습자료나 서버 임시 초안을 만들지 않는다.
- 학습자료 저장 뒤에도 본문을 편집할 수 있다. 단, 같은 학습자료의 퀴즈 생성이 진행 중인 동안에는 생성 근거를 고정하기 위해 본문 편집을 임시 차단하고, 생성이 성공 또는 실패로 끝나면 다시 허용한다. 세부 전이는 [퀴즈 PRD의 학습자료 잠금](prd-quiz-learning.md#학습자료-잠금)을 따른다.
- 제목은 본문 잠금과 관계없이 수정할 수 있다.
- 학습자료를 수정해도 이미 생성된 문제 세트, 풀이 회차와 결과는 바뀌지 않는다. 이후 새 문제 세트는 생성 접수 시점의 최신 학습자료를 근거로 한다.

### 저장한 학습자료 조회

- 사용자는 자신의 학습자료만 최근 수정 순으로 조회하고 제목 일부로 검색할 수 있다.
- 목록은 모바일에서 한 번에 다루기 쉬운 페이지 단위로 이동하며, 한 페이지 크기와 정확한 요청·응답은 공유 API 계약을 따른다.
- 목록에는 자료를 구분하는 제목, 출처, 수정 시각과 생성 중 임시 잠금 상태만 보여주고 전체 본문은 상세 조회에서 확인한다.
- 자료가 없을 때와 제목 검색 결과가 없을 때를 구분하며, 범위를 벗어난 페이지를 자료 삭제나 오류로 표현하지 않는다.

### 붙여넣기

- 사용자가 붙여넣은 텍스트는 프론트 편집 상태일 뿐 서버 import 리소스가 아니다.
- 사용자가 저장하면 현재 제목과 본문을 곧바로 학습자료로 저장한다.
- 공백뿐인 본문과 20,000자를 넘는 본문은 저장 전에 수정할 수 있게 안내한다.

### Notion 일회성 복사

- Notion 연결은 사용자별 Public OAuth를 사용하며 특정 워크스페이스로 제한하지 않는다. 사용자는 자신이 권한을 부여할 수 있는 워크스페이스를 연결할 수 있다.
- 웹 OAuth 성공은 페이지 선택으로 이어지고, 사용자가 취소하거나 연결이 실패하면 입력 방식 선택으로 돌아간다. 복귀 URL에는 성공·취소·실패 결과와 공개 오류 코드만 남기고 연결 상태를 다시 확인한 뒤 query를 제거한다.
- 사용자 한 명은 활성 Notion 워크스페이스 연결을 한 개만 가진다. 다른 워크스페이스를 연결하려면 현재 연결을 먼저 해제해야 하며, 인증 화면에서 다른 워크스페이스를 선택하면 새 자격을 폐기하고 기존 연결을 유지한다.
- 서버는 Notion 접근 자격을 암호화해 보관하고 제공자가 허용하는 갱신 절차로 갱신한다. 갱신할 수 없거나 재동의가 필요하면 기존 연결을 임의로 삭제하지 않고 재인증이 필요한 상태로 안내한다.
- 연결 해제는 Notion 쪽 접근 권한 철회를 먼저 시도하고, 철회가 완료됐거나 이미 철회된 상태임을 확인한 뒤 로컬 연결 정보를 삭제한다. 해제 성공 뒤에는 이전에 시작한 승인 callback이 연결을 다시 만들 수 없다. 일시적 제공자 장애로 철회 여부를 확인할 수 없으면 연결 정보를 보존하고 다시 시도할 수 있게 한다.
- 사용자는 연결된 워크스페이스에서 접근을 허용한 페이지 하나를 선택한다. 일반 페이지와 데이터베이스의 개별 행 페이지는 선택할 수 있지만 데이터베이스 자체는 선택할 수 없다. 하위 페이지는 상위 페이지에 자동 포함하지 않고 가져올 각 페이지를 별도로 선택한다.
- 현재 목록에 없는 페이지 접근을 추가하려면 같은 워크스페이스의 OAuth 승인을 다시 진행한 뒤 페이지 목록을 새로고침한다. 재인증 전 선택했던 `pageId`는 서버나 프론트에 복원용으로 저장하지 않으며, 승인 뒤 사용자가 목록에서 다시 선택한다.
- MVP의 `접근 페이지 추가`, `다른 워크스페이스 연결`, `연결 해제` 행동은 Notion 페이지 선택 화면에만 둔다. 마이페이지의 연동 관리 화면은 후속 범위다.
- 제목 검색에서 접근 가능한 페이지가 누락되면 사용자가 입력한 Notion URL에서 page UUID를 추출해 같은 일회성 복사를 시도할 수 있다. 입력 URL과 `pageId`는 가져오기 기록으로 저장하지 않는다.
- 서버는 선택한 페이지를 요청 시점에 한 번 복사해 제목과 본문을 반환한다. 같은 페이지를 여러 번 선택해 복사하는 것을 막지 않으며, 각 성공 결과는 새로운 프론트 편집 상태다.
- 최신 페이지 제목과 enhanced Markdown 구조·링크 텍스트를 유지한다. Markdown 첫 줄을 임의로 제거하지 않고 fenced·inline code 밖의 줄바꿈 표시 `<br>`만 Markdown 강제 줄바꿈으로 치환한다. 코드 예시의 `<br>` 리터럴은 원문을 유지한다.
- 이미지·영상·파일 등 미디어 본체와 녹취는 학습자료 본문에 포함하지 않는다. 미디어에 캡션이나 대체 텍스트가 있으면 그 텍스트는 유지한다. 코드 예시는 제외하고 속성을 포함한 unknown 태그까지 불완전 표시로 판정하며, 이런 표시가 있는 본문은 추가 회수나 부분 반환 없이 가져오기 전체를 실패로 처리한다.
- 이 반환값은 아직 저장된 학습자료나 서버 초안이 아니다. 사용자는 프론트에서 확인·수정한 뒤 붙여넣기와 같은 저장 행동으로 학습자료를 만든다.
- 서버는 빈 본문과 제한을 넘는 제목·본문도 가져오기 단계에서는 자르지 않고 성공 응답으로 전체 반환한다. 프론트는 제목의 앞뒤 Unicode 공백을 제거한 결과가 1..255 code point이고 본문에 비공백 문자가 하나 이상 있으며 전체 본문이 1..20,000 code point일 때만 `저장하고 퀴즈 만들기`와 `자료만 저장`을 활성화한다.
- 두 행동은 같은 학습자료 저장 경계를 사용하며, 전자는 저장 성공 뒤 해당 자료가 선택된 퀴즈 생성 조건으로 이어지고 후자는 저장한 자료 확인으로 끝난다.
- 저장 뒤 Notion 원본과 학습자료 사이에는 자동·수동 동기화가 없다. Notion 원본의 이후 변경은 저장된 학습자료에 반영되지 않는다.

### 폐기된 MVP 전제

- 파일 업로드, 서버 import job, `importId`, 서버 preview·draft와 만료 API는 이번 MVP 계약이 아니다.
- 과거 문서나 구현 초안에 이 전제가 남아 있어도 새 API를 만들 근거로 사용하지 않는다.

## 확정된 세부 정책

- 제목은 앞뒤 Unicode 공백을 제거해 저장하고, 정리한 결과가 최대 255자여야 한다.
- 제목과 본문의 글자 수는 Unicode code point 기준으로 계산한다.
- 본문은 유효성 검사나 저장 과정에서 앞뒤 공백을 제거하거나 자동으로 자르지 않는다.

## 상태와 예외

| 상태/조건 | 사용자에게 보이는 동작 | 복구 행동 |
| --- | --- | --- |
| 편집 중 | 제목·본문과 현재 글자 수를 확인 | 수정, 저장 또는 취소 |
| 빈 제목 | 제목이 필요함을 해당 입력에 안내하고 저장하지 않음 | 제목 입력 |
| 빈 본문 | 가져온 전체 편집 상태는 보존하되 두 저장 행동을 비활성화하고 이유를 안내 | 본문 입력 |
| 20,000자 초과 | 초과 사실과 줄여야 할 분량을 이해 가능하게 안내 | 프론트에서 편집 후 다시 저장 |
| Notion 연결 없음·OAuth 승인 흐름 만료 | 연결이 없거나 승인 흐름을 계속할 수 없다는 의미와 대체 입력을 안내 | 연결 상태 재조회 뒤 현재 상태에 맞는 OAuth를 처음부터 다시 시작하거나 붙여넣기 선택 |
| Notion 재인증 필요 | 현재 연결로 계속할 수 없음을 안내하고 기존 편집 상태를 보존하되 페이지 선택은 복원하지 않음 | 같은 워크스페이스 재인증 뒤 페이지 재선택 또는 붙여넣기 선택 |
| Notion 페이지 접근 불가 | 선택한 페이지를 가져올 수 없음을 안내 | 접근 가능한 다른 페이지 선택 또는 Notion 권한 확인 |
| Notion 내용 불완전 | 부분 본문을 편집 상태로 만들지 않고 완전한 복사를 확인할 수 없음을 안내 | 같은 페이지 재시도 또는 붙여넣기 선택 |
| Notion 일시적 장애 | 현재 선택과 기존 편집 상태를 보존 | 같은 행동 재시도 또는 붙여넣기 선택 |
| 저장 통신 실패 | 프론트 편집 내용을 보존 | 같은 내용으로 재시도 |
| 퀴즈 생성 중 본문 수정 | 진행 중인 생성이 현재 본문을 근거로 사용하고 있어 일시적으로 수정할 수 없음을 안내 | 제목은 수정하거나, 생성 종료를 확인한 뒤 보존한 편집 내용으로 다시 저장 |

## 수용 기준

- [ ] 사용자는 붙여넣은 일반 텍스트를 프론트에서 수정한 뒤 별도 import·preview 단계 없이 학습자료로 저장할 수 있다.
- [ ] 사용자는 자신의 학습자료를 최근 수정 순으로 페이지 이동하며 확인하고 제목 일부로 검색할 수 있다.
- [ ] 목록에는 제목·출처·수정 시각·생성 중 임시 잠금 상태가 보이며 전체 본문은 선택한 자료의 상세에서 확인할 수 있다.
- [ ] 학습자료가 없는 상태, 제목 검색 결과가 없는 상태와 조회 실패를 서로 구분할 수 있다.
- [ ] 사용자는 Public OAuth로 임의의 Notion 워크스페이스 하나를 연결하고, 허용된 페이지 하나를 선택해 제목과 Markdown 본문을 일회성 복사할 수 있다.
- [ ] 사용자에게 활성 워크스페이스 연결은 한 개만 유지되며, 다른 워크스페이스는 현재 연결을 해제한 뒤에만 연결할 수 있다.
- [ ] 연결·재인증 중 다른 워크스페이스를 승인해도 새 자격은 저장되지 않고 기존 워크스페이스 연결이 유지된다.
- [ ] 다른 워크스페이스 승인 충돌은 현재 자격의 재인증 필요 상태와 구분되며, 사용자는 기존 연결 유지 또는 연결 해제 후 변경 중 하나를 선택할 수 있다.
- [ ] 연결 해제는 Notion 권한 철회가 완료됐거나 이미 철회됐음을 확인한 뒤 로컬 연결 정보를 삭제하고, 해제 전에 시작한 callback으로 연결을 다시 만들지 않으며, 일시적 실패에는 기존 연결 정보를 잃지 않는다.
- [ ] 하위 페이지는 자동으로 합쳐지지 않으며 사용자가 별도로 선택할 때만 별도 가져오기 결과가 된다. 같은 페이지를 다시 가져오는 것은 허용한다.
- [ ] 페이지 선택 목록은 일반 페이지와 데이터베이스의 개별 행 페이지를 허용하고 데이터베이스 자체는 제외하며, 수정 시각 최신순 20개·제목 검색·opaque cursor 더보기와 새로고침을 제공한다.
- [ ] 페이지 제목 검색어가 바뀌면 이전 결과와 cursor를 초기화하고 새 검색의 첫 목록부터 보여준다.
- [ ] 제목 검색에서 접근 페이지가 누락되면 Notion URL의 page UUID로 같은 복사를 시도할 수 있고 입력 URL과 `pageId`는 가져오기 기록으로 남지 않는다.
- [ ] 같은 워크스페이스 OAuth 재승인으로 접근 페이지를 추가할 수 있고, 복귀 뒤 이전 `pageId`를 복원하지 않은 채 목록에서 다시 선택한다.
- [ ] 미디어 본체는 제외하되 캡션·대체 텍스트는 유지하고 텍스트 구조는 Markdown으로 보존하며, 의도적으로 제외한 미디어 외의 텍스트를 완전히 변환할 수 없으면 부분 본문 없이 가져오기가 실패한다.
- [ ] Notion 연결 없음 또는 OAuth 승인 흐름 만료·재인증 필요·다른 워크스페이스 승인 충돌·페이지 접근 불가·내용 불완전·일시적 장애를 구분하고, 각 실패에서 [학습자료 흐름](../ux/flow-content-import.md#취소와-실패)이 정한 선택·편집 상태를 보존한 채 복구하거나 붙여넣기로 전환할 수 있다.
- [ ] 웹 OAuth는 full-page redirect 뒤 원래 가져오기 흐름으로 돌아오며, callback query나 화면에 Notion 원시 오류와 접근 자격을 노출하지 않는다.
- [ ] OAuth 성공은 페이지 선택으로, 취소·실패는 입력 방식 선택으로 이동하며, 프론트는 callback query를 제거하고 연결 상태를 다시 조회한다.
- [ ] Notion 연결 관리 행동은 페이지 선택 화면에서 제공하고, 마이페이지 연동 관리는 후속 범위로 남긴다.
- [ ] 미입력·공백뿐인 제목은 저장되지 않고, 사용자가 직접 유효한 제목을 입력해야 한다.
- [ ] 앞뒤 공백을 제거한 제목은 255자까지 저장되고 256자부터 저장되지 않는다.
- [ ] 제목·본문 입력 아래 글자 수 counter는 현재 값과 제한을 함께 표시하고, 제한 초과 시 오류 색상으로 바뀌었다가 사용자가 제한 안으로 수정하면 일반 색상으로 돌아온다.
- [ ] 빈 본문과 20,000자 초과 본문은 저장되지 않고 사용자가 입력을 잃지 않은 채 수정할 수 있다. Notion 가져오기 응답은 20,000자를 넘는 전체 본문을 자르지 않으며 제한을 충족할 때까지 두 저장 행동을 모두 차단한다.
- [ ] 빈 Notion 본문도 가져오기에는 성공하지만, 제목·본문이 저장 조건을 모두 충족하기 전에는 두 저장 행동을 실행할 수 없다.
- [ ] 유효한 편집 상태에서 `저장하고 퀴즈 만들기`를 선택하면 저장 성공 뒤 해당 자료의 퀴즈 생성 조건으로, `자료만 저장`을 선택하면 저장한 자료 확인으로 이어진다.
- [ ] 저장 전 취소하거나 Notion 복사만 완료한 상태에서는 서버 학습자료·초안·import job이 생기지 않는다.
- [ ] 저장 뒤 Notion 원본을 바꿔도 학습자료가 자동 또는 수동으로 동기화되지 않는다.
- [ ] 성공한 문제 세트가 있어도 진행 중인 생성이 없으면 학습자료 제목과 본문을 수정할 수 있고, 기존 문제 세트·풀이·결과는 바뀌지 않는다.
- [ ] 퀴즈 생성 중에는 본문 수정만 임시 차단되며 이유와 복구 행동을 확인할 수 있고, 생성이 성공 또는 실패로 끝나면 다시 수정할 수 있다.
- [ ] 학습자료를 수정한 뒤 새 문제 세트를 만들면 생성 접수 시점의 최신 본문이 새 문제의 근거가 된다.
- [ ] MVP 화면과 안내에서 로컬 파일 업로드를 지원 입력으로 제시하지 않는다.

## 이번 구현과 후속 범위

- **확정·이번 구현:** 기존 붙여넣기와 학습자료 저장·조회를 유지하면서, 사용자별 Notion Public OAuth 연결, 접근 페이지 선택, 완전한 단일 페이지 일회성 복사와 두 저장 후속 행동을 웹과 서버에 연결한다. 웹 OAuth는 full-page redirect로 진행한다.
- **확정·후속 구현:** 학습자료 수정 시 생성 중 본문 변경을 거절하고 생성 종료 뒤 다시 허용한다. 제목 수정은 생성 중에도 허용한다.
- **확정·후속 구현:** 네이티브 앱의 Notion OAuth 복귀와 연결 화면은 이번 웹·서버 범위 뒤에 다룬다. 서버의 연결·페이지·가져오기 계약은 특정 클라이언트 플랫폼에 종속하지 않는다.
- **후속 연동:** 학습자료 삭제와 실제 외부 문제 생성 서비스 연결은 이번 작업에 포함하지 않는다.
- 기존 QuizSet·문제·풀이·결과는 학습자료 수정과 독립적인 불변 기록으로 보존하며 새 QuizSet만 생성 접수 시점의 최신 저장 본문을 근거로 사용한다.

## 열린 질문

- 여섯 가지 Notion 실패 상태의 정확한 사용자 문구와 화면 내 제시 방식은 별도 제품·UX 검토에서 확정한다. 공개 오류 의미와 복구 행동은 공유 API 계약과 흐름 문서를 따른다.
- 서버가 20개씩 반환하는 페이지 목록을 화면에서 한 번에 5개 또는 10개 중 몇 개씩 노출할지는 후속 화면 설계에서 확정한다. 글자 수 counter의 정확한 SEED 컴포넌트와 색상 token은 확정된 초과·정상 전환 행동을 유지하는 범위에서 정한다.
