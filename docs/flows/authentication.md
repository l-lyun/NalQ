# 사용자 흐름: 자체 인증

- 상태: 초안
- 관련 기능: [자체 로그인](../features/01-local-auth.md)

## 시작 조건

- 사용자가 로그인 전 앱을 열거나 보호된 화면에 접근한다.

## 기본 로그인 흐름

1. 앱이 인증되지 않은 상태를 확인하고 로그인 화면을 보여준다.
2. 사용자가 자체 계정의 식별자와 비밀번호를 입력한다.
3. 시스템이 입력 형식을 확인하고 인증을 요청한다.
4. 인증에 성공하면 세션을 만들고 원래 목적지 또는 홈으로 이동한다.
5. 홈은 해당 사용자의 학습 상태를 불러온다.

## 회원가입 흐름

1. 사용자가 로그인 화면에서 회원가입을 선택한다.
2. 필수 계정 정보를 입력하고 약관 등 필수 동의를 완료한다.
3. 시스템이 입력 형식과 중복 여부를 확인한다.
4. 계정 생성에 성공하면 정책에 따라 로그인 상태로 전환하거나 로그인 화면으로 안내한다.

## 로그아웃 흐름

1. 사용자가 프로필의 설정에서 로그아웃을 선택한다.
2. 시스템이 인증 상태와 화면의 개인 학습정보를 제거한다.
3. 로그인 화면으로 이동한다.
4. 뒤로가기로 보호 화면에 다시 진입할 수 없다.

## 예외와 복구

- 입력 형식 오류: 해당 필드 가까이에서 수정 방법을 안내한다.
- 인증 실패: 민감한 계정 존재 정보를 노출하지 않는 공통 안내와 재입력을 제공한다.
- 네트워크 또는 서버 오류: 입력을 가능한 범위에서 유지하고 재시도할 수 있게 한다.
- 세션 만료: 현재 작업을 보존할 수 있으면 보존하고 다시 로그인하도록 안내한다.

## 열린 질문

- 회원가입 직후 자동 로그인 여부
- 이메일 인증과 비밀번호 복구 흐름
- 인증 만료 중 작성 중인 붙여넣기나 답안의 보존 범위
