## 문서 책임

이 문서는 최종 제출은 끝났지만 서술형 자기평가가 남은 회차에 다시 들어왔을 때 필요한 안내만 정의한다. 최종 제출 전 답안은 화면을 벗어난 뒤 복구하지 않는다.

## 확정 사항

- 최종 제출 뒤 서술형 자기평가가 남아 있으면 기존 자기평가 화면으로 바로 이어진다.
- 아직 제출하지 않은 풀이에서 새로고침하거나 화면을 나가면 작성한 답과 문항 위치는 복구하지 않는다. 다시 들어오면 첫 문항부터 새로 푼다.
- 최종 제출 중 네트워크가 끊겨도 현재 화면이 답과 제출 UUID를 유지하는 동안에는 같은 제출을 다시 시도할 수 있다.
- 새로고침·앱 종료로 그 상태를 잃은 뒤에는 서버가 미완료 답안을 복원하거나 제출 성공 여부를 자동 판별하지 않는다.
- 사용자의 행동이 필요한 조회 실패에서만 일반 오류와 `다시 시도`를 보여준다.

## 미완료 서술형 자기평가

별도 복구 화면을 만들지 않고 기존 서술형 자기평가 화면을 그대로 사용한다.

- 상단 제목: `서술형 자기평가`
- 진행 정보: `남은 1개`
- 안내: `남은 자기평가를 이어서 해주세요.`
- 기존 구성: 문제, 내 답, 모범 답안, 핵심 포인트, 이해도 선택
- 완료 행동: 기존 자기평가 완료 CTA

서버, attempt, 저장 성공 여부는 설명하지 않는다. 사용자는 남은 평가를 이어서 하면 된다.

## 사용자에게 보이는 예외

| 조건 | 문구 | 행동 |
| --- | --- | --- |
| 결과 또는 다음 단계를 불러오지 못함 | `결과를 불러오지 못했어요. 다시 시도해 주세요.` | `다시 시도` |
| 제출 전 작성 중인 답이 있는 상태에서 나가기 | `작성 중인 답이 사라져요. 나갈까요?` | `계속 풀기`, `나가기` |

오류 원인이 응답 유실, 현재 화면 상태 소실, 서버 조회 중 무엇인지 구분해 보여주지 않는다.

## 반응형·접근성

- 320px부터 한 열을 유지하고 sheet·dialog와 하단 CTA가 키보드 및 safe area에 가려지지 않는다.
- 큰 글자에서 진행 정보와 버튼 문구를 줄임표로 자르지 않는다.
- 나가기 확인 dialog의 제목과 설명을 연결하고 취소가 안전한 기본 행동이 되게 한다.
- 이동 뒤에는 자기평가 제목으로 포커스를 옮긴다.

## 인수 조건

- [ ] 제출 전 화면을 새로 열면 이전 문항 위치와 답안을 복원하거나 `이어서 풀기`를 제안하지 않는다.
- [ ] 작성 중 나가려 하면 답이 사라진다는 확인을 제공한다.
- [ ] 현재 화면에서 제출 응답을 받지 못하면 같은 UUID와 답으로 다시 시도할 수 있다.
- [ ] 미완료 서술형 자기평가는 기존 자기평가 화면으로 바로 이어진다.
- [ ] 정상적인 서버 조회와 저장 성공에는 별도 내부 처리 안내가 나타나지 않는다.
- [ ] 사용자가 해결해야 하는 실패에서만 일반 오류와 재시도 행동이 나타난다.

## 비범위

- 제출 전 답안의 영속 저장과 복구
- attempt UUID 생성과 서버 중복 처리 구현
- API 상태명과 내부 저장 성공·실패 상태
- 기존 문제 풀이와 자기평가 UI의 재설계
