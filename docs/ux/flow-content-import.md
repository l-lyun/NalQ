# [Flow] 학습자료 만들기

- 관련 기능: [학습자료 만들기](../prd/prd-content-import.md)
- 공유 계약: [학습자료·퀴즈 API 계약](../contracts/contract-api-quiz-learning.md)

## 문서 책임

이 문서는 붙여넣기와 Notion 일회성 복사에서 저장까지의 순서, 취소와 실패 복구를 정의한다. 입력 정책은 기능명세가, HTTP 경계는 공유 계약이 책임진다.

## 사용자 목표

가진 글을 확인·수정해 퀴즈를 만들 수 있는 학습자료로 저장한다.

## 시작 조건

- 로그인한 사용자가 홈의 새 학습 또는 학습 영역의 자료 추가를 선택한다.

## 완료 조건

- 사용자가 확인한 제목과 20,000자 이하 본문이 하나의 학습자료로 저장되고, 자료 상세 또는 퀴즈 생성 단계로 이동할 수 있다.

## 공통 저장 흐름

1. 사용자는 붙여넣기 또는 Notion 중 하나를 선택한다.
2. 프론트 편집 화면에서 제목, 본문과 변환 경고가 있으면 경고를 확인한다.
3. 사용자가 제목과 본문을 수정한다.
4. 시스템은 빈 본문과 20,000자 제한을 확인한다.
5. 사용자가 저장하면 현재 제목·본문을 학습자료 생성 요청으로 한 번 전송한다.
6. 저장 성공 후 자료 상세 또는 퀴즈 생성 단계로 이동한다.

## 붙여넣기 분기

1. 사용자가 일반 텍스트를 붙여넣는다.
2. 프론트는 텍스트를 즉시 편집 상태에 두고 서버 import·preview 요청을 만들지 않는다.
3. 사용자는 공통 저장 흐름으로 진행한다.

## Notion 분기

1. Notion 연결이 없다면 사용자가 필요한 접근을 승인한다.
2. 사용자는 허용된 범위에서 페이지 하나를 선택한다.
3. 서버는 그 페이지를 한 번 복사해 제목, 본문과 변환 경고를 반환한다.
4. 프론트는 반환값을 편집 상태로 전환한다. 이 시점에는 학습자료·import job·서버 draft가 없다.
5. 사용자는 공통 저장 흐름으로 진행한다.

## 취소와 실패

| 조건 | 보존해야 할 정보 | 안내 | 복구 행동 |
| --- | --- | --- | --- |
| 저장 전 취소 | 서버에는 없음 | 학습자료가 만들어지지 않음을 안내 | 이전 화면으로 이동 |
| 빈 본문·20,000자 초과 | 프론트 제목·본문 | 수정할 필드와 이유 | 편집 후 저장 재시도 |
| Notion 연결 취소·권한 없음·철회 | 선택한 입력 방식 | 페이지를 복사할 수 없는 이유 | 권한 재연결 또는 붙여넣기로 전환 |
| Notion 복사 통신 실패 | 선택한 페이지 식별 정보 | 학습자료가 아직 만들어지지 않았음을 안내 | 같은 페이지 복사 재시도 |
| 저장 통신 실패 | 프론트 제목·본문·경고 확인 상태 | 저장 여부를 확인하지 못했음을 안내 | 같은 저장 요청 재시도 |
| 중복 저장 응답 유실 | 프론트 제목·본문과 멱등 키 | 같은 자료를 새로 만들지 않음 | 같은 키로 재전송 |

## 중단과 재개

- 붙여넣기와 Notion 복사 결과는 저장 전 프론트 편집 상태다. MVP는 서버 초안이나 만료 후 복구를 제공하지 않는다.
- 앱·웹 종료 뒤 미저장 편집을 복원한다고 약속하지 않는다.
- 저장 성공 뒤 본문은 퀴즈 생성 요청 전까지 편집 가능하다. 생성 접수 이후 흐름은 [퀴즈 생성부터 복습까지](flow-quiz-solving.md)가 책임진다.

## 폐기된 흐름

- 로컬 파일 선택·파싱, import job 대기, `importId`로 preview 조회, 서버 draft 만료와 동기화 새로고침은 이번 MVP 흐름에 포함하지 않는다.

## 열린 질문

- Notion 인증이 만료됐을 때 재연결 후 이전 페이지 선택을 복원할 수 있는지
