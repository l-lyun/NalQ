# 데이터 계약 원장

- 상태: 초안

제품 영역 사이에서 동일한 의미로 사용해야 하는 데이터의 정의, 소유권, 생명주기와 개인정보 취급 원칙을 기록한다. 물리 DB 스키마 자체의 원장은 아니다.

## 초기 핵심 개념

- 사용자
- 학습자료와 원문 출처
- 문제 세트, 문제, 정답 기준과 원문 근거
- 본 퀴즈 회차, 사용자 답안, 채점 결과와 복습 세션
- 복습 상태
- 향후 경험치, 레벨, 친구 관계, 꾸미기 자산

## 확정 전 필요한 결정

- 사용자 계정과 학습자료 삭제 시 파생 문제·풀이의 처리
- Notion 원본 식별자 및 연결 토큰의 보관 범위
- 원문과 LLM 요청·응답의 보존 기간
- 생성·채점 모델 버전 및 평가 근거의 추적 범위
- 본 퀴즈 회차와 복습 해결 상태의 보존·삭제 연계

물리 테이블과 인덱스는 서버 구현 결정으로 관리하되, 여기의 의미와 생명주기를 위반하지 않아야 한다.
