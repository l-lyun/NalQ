# 기능명세: 자체 로그인

- 상태: 초안
- 관련 흐름: [인증 흐름](../flows/authentication.md)

## 사용자 문제

사용자는 자신의 학습자료와 풀이 기록을 안전하게 저장하고 여러 방문에 걸쳐 이어서 사용하려면 개인 계정이 필요하다.

## 목표

외부 소셜 계정에 의존하지 않고 가입, 로그인, 로그아웃할 수 있게 한다.

## 범위

- 자체 회원가입
- 로그인 및 인증 상태 유지
- 로그아웃
- 인증이 필요한 화면 보호
- 입력 오류와 인증 실패 안내

## 비범위

- 초기 배포 전 소셜 로그인
- 조직 계정, 관리자 역할, 다중 프로필
- 아직 합의되지 않은 이메일 인증과 비밀번호 복구 정책

## 핵심 규칙

- 로그인하지 않은 사용자가 보호 화면에 접근하면 인증 흐름으로 안내한다.
- 인증 실패는 계정 존재 여부 같은 민감한 정보를 불필요하게 드러내지 않는다.
- 로그아웃 후에는 보호된 학습정보가 화면에 남지 않아야 한다.
- 비밀번호 원문이나 인증 토큰을 제품 로그 및 문서에 남기지 않는다.

## 수용 기준

- 유효한 가입 정보로 계정을 만든 사용자는 로그인할 수 있다.
- 잘못된 입력 또는 인증 실패 시 사용자는 수정 가능한 오류 안내를 받는다.
- 로그인 상태에서 앱을 다시 열었을 때 정책이 허용하는 범위에서 세션이 유지된다.
- 로그아웃한 사용자는 보호 화면을 볼 수 없고 로그인 화면으로 이동한다.
- 소셜 로그인 선택지는 초기 버전에 표시하지 않는다.

## 열린 질문

- 로그인 식별자를 이메일로 고정할지 사용자명도 허용할지
- 이메일 소유 확인을 초기 가입의 필수 단계로 둘지
- 비밀번호 최소 정책과 재설정 방식
- 세션 유지 기간과 다중 기기 처리
- 계정 탈퇴 및 데이터 삭제의 MVP 포함 여부
