# [Product Foundation] OpenMD

## 제품 개요

### 한 문장 정의

OpenMD는 사용자가 가진 글을 학습자료로 가져와 AI가 만든 퀴즈로 풀고, 자신의 이해도를 확인하도록 돕는 학습 앱이다.

### 해결하려는 문제

글을 읽는 것만으로는 이해했는지 확인하기 어렵고, 직접 문제를 만드는 데 시간이 든다. OpenMD는 기존 지식 자료를 다시 입력하는 부담을 낮추고, 읽기에서 회상과 피드백으로 이어지는 짧은 학습 루프를 만든다.

### 핵심 사용자 여정

1. 사용자가 자체 계정으로 로그인한다.
2. Notion 단일 페이지를 한 번 복사하거나 텍스트를 붙여넣어 학습자료로 저장한다.
3. 문제 유형, 난이도와 최대 문제 수를 선택한다.
4. 학습자료에 근거해 생성된 문제를 풀고 서술형은 자기평가한다.
5. 결과와 원문 근거를 확인하고 가장 최근 완료 회차에서 틀린 문제를 다시 푼다.

### 확정된 초기 범위

- 자체 회원가입과 로그인. 소셜 로그인은 앱 배포 이후로 미룬다.
- 두 가지 학습자료 입력: Notion 단일 페이지 일회성 복사, 텍스트 붙여넣기
- 최대 20,000자 학습자료 본문과 퀴즈 생성 뒤 근거 보존을 위한 본문 잠금
- 네 가지 문제 유형: 객관식, 빈칸 채우기, 단답형, 서술형
- `쉬움`, `보통`, `어려움` 난이도와 최대 `5`, `10`, `15`문제 선택
- 학습자료 기반 문제 생성, 규칙 기반 자동 채점과 서술형 자기평가
- 가장 최근 완료한 본 퀴즈 회차의 미해결 문제 다시 풀기
- 하단 탭 세 개: 홈, 학습, 프로필
- 학습자료와 틀린 문제 다시 풀기를 별도 하단 탭으로 분리하지 않고 학습 안에서 다룬다.
- 학습과 문제 만들기도 하나의 학습 흐름에서 이어지게 한다.

### 이후 확장 후보

아래 항목은 제품 방향에는 포함되지만 초기 출시 범위와 상세 정책은 아직 확정하지 않는다.

- 문제 풀이 경험치와 레벨
- 레벨 또는 성과 기반 랭킹
- 친구 맺기와 친구가 만든 문제 풀기
- 상점과 포인트
- 도트 또는 간결한 캐릭터, 프로필, 방 꾸미기

### 비범위

- 초기 배포 전 소셜 로그인
- `.txt`, `.md`를 포함한 로컬 파일 업로드와 Notion 동기화
- 서버 중간 풀이 저장, 여러 기기 이어 풀기와 서술형 LLM 채점
- 확정되지 않은 게임 경제, 랭킹 산식, 친구 공개 범위를 선행 구현하는 것
- 원문에 근거하지 않는 일반 지식 시험을 핵심 기능으로 삼는 것

### 성공의 초기 정의

- 사용자가 지원되는 방법 중 하나로 자료를 가져와 첫 퀴즈를 완주할 수 있다.
- 사용자가 정답 여부뿐 아니라 무엇을 다시 확인해야 하는지 이해할 수 있다.
- 다시 방문한 사용자가 중단한 학습 또는 다시 풀 문제를 빠르게 찾을 수 있다.

구체적인 지표와 목표치는 실제 사용 데이터를 수집하기 전에 별도로 합의한다.

### 열린 질문

- 1차 배포 플랫폼과 화면 크기 범위
- 대상 사용자의 우선순위: 학생, 직장인, 자격시험 학습자 등
- 무료 사용량, 결제, LLM 비용 제한 정책
- 자료와 생성 문제의 보관 기간 및 삭제 정책
- MVP 이후 다시 풀기 시점 추천 규칙
- 경험치·랭킹·친구·꾸미기 기능의 출시 순서와 운영 정책

## 제품 원칙

### 1. 읽기보다 회상을 돕는다

원문 보관 자체보다 문제를 풀고 피드백을 받는 학습 행동을 우선한다. 화면은 사용자가 다음 학습 행동을 선택하는 데 드는 시간을 줄여야 한다.

### 2. 자료 입력의 출처가 달라도 학습 경험은 일관되게 한다

MVP 입력은 텍스트 붙여넣기와 사용자가 선택한 Notion 단일 페이지의 일회성 복사만 지원한다. 두 입구 모두 프론트에서 확인·수정한 뒤 같은 학습자료 저장과 문제 생성·풀이·결과 흐름을 제공하며, 로컬 파일 업로드는 후속 범위로 둔다.

### 3. AI 결과를 확정 사실처럼 숨기지 않는다

생성 문제는 원문과 생성 모델의 한계를 가질 수 있다. 자동 채점은 정해진 규칙의 범위를, 서술형은 LLM 채점 없이 사용자가 모범 답안·핵심 포인트로 자기평가한다는 사실을 드러내고 원문을 확인할 수 있어야 한다.

### 4. 다음 행동은 하나를 가장 선명하게 제안한다

홈은 모든 기능의 목록이 아니라 지금 이어서 할 학습을 우선 보여준다. 미완료 풀이, 틀린 문제 다시 풀기, 문제 없는 자료처럼 맥락에 맞는 행동을 우선한다.

### 5. 점수보다 학습 통제감을 지킨다

난이도와 문제 유형을 사용자가 조절할 수 있게 하고, 오답은 처벌보다 다시 이해하기 위한 정보로 표현한다.

### 6. 게임 요소는 학습을 보조한다

경험치, 랭킹, 친구, 꾸미기는 지속 동기를 높이는 수단이다. 과도한 경쟁, 무의미한 반복 풀이, 과금 우위가 학습 가치를 해치지 않도록 상세 정책을 별도로 검증한다.

### 의사결정 점검 질문

- 이 결정이 첫 문제 풀이까지의 단계를 줄이는가?
- 사용자가 AI 결과의 근거와 불확실성을 이해할 수 있는가?
- 실패 후 복구할 방법이 보이는가?
- 미래 게임 요소 없이도 학습 가치가 성립하는가?

## 전역 내비게이션

### 확정 구조

로그인 후 주요 화면은 하단 탭 세 개를 사용한다.

| 탭 | 사용자 질문 | 주요 책임 |
| --- | --- | --- |
| 홈 | 지금 무엇을 하지? | 다음 학습 행동, 다시 풀 문제 요약, 최근 활동 |
| 학습 | 무엇으로 공부하지? | 자료 가져오기·관리, 문제 생성, 풀이와 다시 풀기 진입 |
| 프로필 | 나는 어떻게 공부하고 있지? | 학습 기록, 계정 및 설정, 향후 친구·캐릭터 |

### 구조 원칙

- 학습자료와 틀린 문제 다시 풀기를 서로 다른 하단 최상위 탭으로 만들지 않는다. 다시 풀기는 학습 메인의 한 섹션에서 진입한다.
- 학습자료 추가와 문제 만들기를 분리된 최상위 목적지로 만들지 않는다.
- 설정은 독립 하단 탭이 아니라 프로필 안에서 접근한다.
- 문제 풀이처럼 몰입이 필요한 흐름에서는 하단 탭을 숨길 수 있지만, 종료 또는 뒤로가기의 결과가 예측 가능해야 한다.
- 로그인 전 화면에는 하단 탭을 표시하지 않는다.

### 탭별 최소 진입점

#### 홈

- 가장 우선인 다음 학습 행동
- 새 학습 시작
- 다시 풀 문제 요약
- 최근 학습자료 및 오늘의 학습 요약

#### 학습

- Notion 단일 페이지 일회성 복사 또는 붙여넣기로 자료 추가
- 보관한 학습자료 탐색
- 자료별 문제 생성, 이어 풀기, 다시 풀기

#### 프로필

- 기본 계정 정보와 설정
- 학습 활동 요약
- 로그아웃과 계정 관리
- 향후 경험치·레벨·친구·꾸미기 진입점

### 홈의 다음 행동 우선순위 제안

아래 순서는 UX 초안이며 데이터와 사용성 검증 후 확정한다.

1. 중단한 문제가 있으면 이어 풀기
2. 틀린 문제가 있으면 다시 풀기
3. 문제가 아직 없는 자료가 있으면 문제 만들기
4. 최근 학습자료가 있으면 다시 학습하기
5. 처음 방문했으면 자료 가져오기

### 열린 질문

- 문제 풀이 중 하단 탭을 숨길 구체적인 조건
- 프로필에서 학습 통계와 설정의 정보 위계
- 학습 탭의 기본 보기: 자료 목록, 진행 중 학습, 다시 풀 문제 중 무엇을 먼저 둘지

## 용어

| 용어 | 의미 | 사용 시 주의 |
| --- | --- | --- |
| 학습자료 | 사용자가 가져온 하나의 글 또는 학습 가능한 콘텐츠 단위 | 원본, 노트, 문서를 혼용하지 않는다. |
| 원문 | 문제와 설명의 근거가 되는 학습자료의 텍스트 | 외부 출처의 전체 페이지와 정규화된 본문을 구분할 필요가 있으면 계약에서 명시한다. |
| 가져오기 | 외부 출처의 텍스트를 프론트 편집 상태로 복사하는 행위 | 저장이나 장기 동기화를 뜻하지 않는다. MVP는 Notion 단일 페이지 일회성 복사만 지원한다. |
| Notion 연결 | 사용자가 허용한 Notion 페이지를 선택해 한 번 복사할 수 있게 하는 과정 | 저장 뒤 자동·수동 동기화는 제공하지 않는다. |
| 문제 세트 | 한 학습자료와 생성 조건을 바탕으로 만든 불변 문제 묶음 | 재생성하면 새 문제 세트를 만들며 이전 세트를 덮어쓰지 않는다. |
| 문제 유형 | 객관식, 빈칸 채우기, 단답형, 서술형 | 하나 이상 선택하며, 유효한 문제가 하나라도 만들어지면 선택 유형 일부가 결과에 없어도 생성에 성공한다. |
| 난이도 | 문제의 회상·추론 부담을 사용자가 조절하는 `쉬움`, `보통`, `어려움` 조건 | API 값은 각각 `EASY`, `NORMAL`, `HARD`다. |
| 본 퀴즈 회차 | 한 문제 세트의 답안을 최종 제출해 만든 불변 학습 기록 | 최종 제출 전 위치·답안은 서버가 저장하지 않는다. API에서는 `attempt`를 사용한다. |
| 자기평가 | 사용자가 서술형의 내 답을 모범 답안·핵심 포인트와 비교해 정답·부분 이해·오답으로 판단하는 행위 | LLM 채점이나 부분 점수를 뜻하지 않는다. |
| review session | 가장 최근 완료한 본 퀴즈 회차의 미해결 문항만 담아 다시 푸는 서버 기록 | API·서버 내부 용어다. 사용자 화면에는 `틀린 문제 다시 풀기`로 표현하며 원래 회차의 답과 판정을 변경하지 않는다. |
| 채점 | 객관식·빈칸·단답형 답을 정답 기준과 비교해 판정하는 행위 | 서술형은 자동 채점하지 않고 자기평가한다. |
| 틀린 문제 다시 풀기 | 최근 완료한 본 퀴즈 회차의 미해결 문제만 모아 본 퀴즈처럼 모두 푼 뒤 채점하는 학습 행동 | 학습 메인의 섹션에서 진입하며 여러 회차를 합치지 않는다. |
| 다음 학습 행동 | 현재 상태에서 홈이 가장 우선해 제안하는 한 가지 행동 | 우선순위 규칙은 검증 전 초안이다. |
