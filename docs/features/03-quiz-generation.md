# 기능명세: 퀴즈 생성과 채점

- 상태: 초안
- 관련 흐름: [문제 풀이 흐름](../flows/quiz-solving.md)

## 사용자 문제

사용자는 읽은 글을 이해했는지 확인할 문제와 피드백을 직접 만들기 어렵다. 특히 서술형 답은 단순 문자열 비교만으로 학습 의도를 평가하기 어렵다.

## 목표

학습자료에 근거한 문제를 원하는 유형과 난이도로 만들고, 풀이 후 이해에 도움이 되는 채점 결과를 제공한다.

## 범위

- 객관식, 단답형, 주관식, 혼합형 선택
- 난이도 선택
- OpenAI LLM API 기반 문제와 정답 기준 생성
- 답안 제출과 채점
- 문제별 결과, 정답 또는 모범 답안, 설명과 원문 근거 확인
- 생성·채점 실패 시 안전한 재시도

## 비범위

- 원문 밖 일반 지식을 중심으로 한 문제 생성
- AI 채점을 절대적인 평가로 보장하는 것
- 경험치, 랭킹, 포인트 지급 정책

## 핵심 규칙

- 모든 문제와 설명은 선택한 학습자료에서 답의 근거를 찾을 수 있어야 한다.
- 객관식은 정답이 모호하지 않고 오답 선택지가 원문과 혼동 가능하되 사실을 왜곡하지 않아야 한다.
- 단답형은 허용 가능한 표현 차이를 고려한다.
- 주관식은 핵심 채점 기준을 바탕으로 평가하고, 애매한 결과를 단정적으로 표현하지 않는다.
- 혼합형의 구체적인 유형 비율은 정책이 정해지기 전 고정하지 않는다.
- 생성 결과가 형식 검증이나 근거 검증을 통과하지 못하면 사용자에게 잘못된 세트를 제시하지 않는다.
- 채점 실패를 오답으로 기록하지 않는다.

## 주요 상태와 예외

| 상태 | 기대 동작 |
| --- | --- |
| 생성 중 | 중복 요청을 방지하고 진행 상태를 알린다. |
| 생성 성공 | 문제 수와 조건을 확인하고 풀이를 시작할 수 있다. |
| 생성 실패 | 사용자의 선택을 유지하고 재시도 또는 자료 확인을 제안한다. |
| 풀이 중 | 진행 상태와 답안을 보존할 수 있다. |
| 채점 중 | 중복 제출을 방지한다. |
| 채점 불확실 | 원문 근거와 평가 이유를 보여주고 단정적 오답 처리를 피한다. |
| 채점 실패 | 답안을 유지하고 재시도하게 하며 오답 통계에 반영하지 않는다. |

## 수용 기준

- 사용자는 네 가지 문제 유형과 제공되는 난이도 중 하나를 선택해 생성을 요청할 수 있다.
- 생성된 각 문제는 연결된 학습자료와 식별 가능한 정답 기준을 가진다.
- 생성 실패 시 조건을 다시 입력하지 않고 재시도할 수 있다.
- 사용자는 문제 유형에 맞는 답을 제출하고 문제별 결과와 설명을 확인할 수 있다.
- 채점 결과에서 원문을 다시 확인할 수 있다.
- 채점 시스템 오류는 오답과 구분되고 사용자의 제출 답안이 보존된다.

## 열린 질문

- 난이도 단계의 수, 명칭, 실제 생성 차이
- 사용자가 선택할 문제 수와 허용 범위
- 객관식 보기 수, 복수 정답 허용 여부
- 단답형과 주관식의 점수 체계 및 불확실 결과 처리
- 생성 전에 사용자가 문제를 미리 검토·편집할 수 있는지
- LLM 비용, 시간 제한, 재생성 횟수와 중복 방지 정책
- 설명에 원문 인용 범위를 어떻게 표시할지
