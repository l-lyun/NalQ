# 학습 보상 상점과 내 공부방

2026-09-08 사용자 승인: 픽셀룸 실험 자산으로 실제 계정별 상점·캐릭터·마이페이지를 구현한다. 아래 보상량과 가격은 사용자 확인을 받았다.

## 제품 정책

- 계정의 시작 잔액은 0코인이다. 기본 꼬마 용, 낮 공부방, 모자 없음, 기본 옷은 항상 보유한다.
- 퀴즈 세트별 최초 풀이 완료에 10코인을 지급한다. 정답률은 무관하며 서술형은 자기평가까지 완료해야 한다. 같은 세트의 재풀이, 복습, 중단에는 지급하지 않는다.
- 기능 도입 전 이미 완료한 세트에는 소급 지급하지 않으며 이후 재풀이에도 지급하지 않는다. 기존 완료 기록을 최초 여부 판단에 포함한다.
- 구매 가격: 고양이·곰 각 50, 밤 공부방 30, 크림 베레모·파란 비니 각 20, 크림 니트 30코인.
- 실제 결제, 현금 환전, 선물, 환불, 경험치·레벨·랭킹은 범위 밖이다.
- 구매와 장착은 별도 행동이다. 구매 전 이름·가격·현재 잔액을 확인한다. 보유 아이템 재구매는 성공으로 취급하고 추가 차감하지 않는다.
- 보유 아이템만 장착 가능하며 캐릭터·방·모자·옷은 독립 슬롯이다. 캐릭터 전환에도 선택한 모자와 옷을 유지한다.
- 잔액·보유·장착은 서버가 결정하며 새로고침, 재로그인, 다른 기기에서도 유지한다. 다른 계정과 공유하지 않는다.
- 학습자료/퀴즈 삭제는 이미 받은 코인과 구매에 영향을 주지 않는다. 계정탈퇴 시 꾸미기와 코인 데이터는 기존 계정 정리 트랜잭션에서 삭제한다.

## 화면과 동선

2026-09-08 사용자 확인: 이번 PR은 실제 기능을 연결하는 단계이며 현재 상품 목록은 최종 상점 디자인이 아니다. 상품 진열·큰 미리보기·구매 상태의 시각적 완성도는 후속 디자인 작업에서 다룬다.

- 전역 3탭은 유지한다. 마이페이지 계정 요약 다음에 `내 공부방` 미리보기, 잔액, `캐릭터 꾸미기`, `상점` 진입을 둔다. 기존 계정·서비스 메뉴는 유지한다.
- `/profile/character`: 저장된 방과 캐릭터 미리보기 → 캐릭터/방/모자/옷별 보유 목록 → `저장하기`. 미저장 선택은 미리보기이며 뒤로 가면 버린다. 저장 성공을 알리고 서버 값으로 갱신한다. 미보유 항목은 상점에서 획득한다.
- `/profile/shop`: 잔액 → 보상 안내 → 카테고리별 현재 카탈로그. 각 상품은 이름·가격·보유 여부와 캐릭터/방/의상 미리보기를 제공한다. 구매 확인 → 처리 중 → 성공 또는 실패·재시도. 구매 후 `캐릭터 꾸미기`에서 장착한다.
- 퀴즈 결과에서 보상 정책과 `상점` 이동을 제공한다. 실제 보상 여부를 추정해 `+10`처럼 표시하지 않는다.
- 하위 페이지는 뒤로가기를 제공하고 하단 전역 탭은 기존 셸 규칙대로 숨긴다. 직접 진입 시 마이페이지로 돌아간다.
- 320px부터 한 열의 화면과 필요 시 2열 상품 목록을 사용한다. 키보드 초점, 이름, 선택 상태, 저장/구매 오류와 재시도, 로딩 상태를 제공한다.
- 캐릭터 그림은 기존 실험의 합성 자산을 재사용한다. 제품에서는 정지 포즈를 사용한다. 걷기 실험은 개발 경로에 유지한다. 정식 걷기 atlas 제작은 별도 범위다.

## 인수 조건

1. 퀴즈 세트 첫 완료에서 잔액이 10 증가하고 동시 완료·재전송·재풀이에도 한번만 지급된다.
2. 서술형 미평가, 중단, 복습에는 코인이 증가하지 않는다.
3. 잔액 부족, 존재하지 않는 상품, 다른 슬롯, 미보유 장착은 서버에서 거절하고 기존 상태를 유지한다.
4. 동시 구매에도 잔액은 음수가 되지 않으며 동일 상품에는 한번만 차감된다.
5. 구매 후 새로고침과 재로그인에서 보유가 유지되고 저장한 장착이 마이페이지에 반영된다.
6. 계정 전환과 늦은 응답이 다른 계정의 캐시·장착을 덮어쓰지 않는다.
7. 기존 계정 설정·로그아웃·탈퇴와 학습 흐름을 보존한다.
