# API 계약 원장

- 상태: 초안

클라이언트와 서버가 함께 사용하는 HTTP API의 입력, 출력, 오류, 권한, 멱등성 기대를 기록한다. 현재 구체적인 엔드포인트는 확정되지 않았다.

## 작성 원칙

- 기능명세가 확정된 뒤 실제 구현 전에 작성하거나 갱신한다.
- 엔드포인트마다 인증 요구, 요청/응답 예시, 오류 코드, 재시도 및 중복 요청 처리를 명시한다.
- OpenAI 또는 Notion의 외부 응답 형식을 클라이언트 계약으로 직접 노출하지 않는다.
- 민감한 토큰과 원문 데이터는 예시에 실제 값을 넣지 않는다.
- 계약 변경은 소비자 영향과 호환 전략을 함께 기록한다.

새 계약은 [API 계약 템플릿](../../templates/api-contract.md)을 사용한다.

## 초기 계약 후보

- 회원가입, 로그인, 로그아웃 및 현재 사용자
- 학습자료 생성·조회·삭제
- Notion 연결 상태, 콘텐츠 선택, 가져오기
- 문제 세트 생성 작업과 상태 조회
- 풀이 세션 저장, 제출, 채점 결과 조회

이 목록은 구현 승인이 아니라 추후 계약 분리 후보이다.
