# 사용자 흐름: 문제 생성과 풀이

- 상태: 초안
- 관련 기능: [퀴즈 생성과 채점](../features/03-quiz-generation.md)

## 시작 조건

- 로그인한 사용자가 유효한 학습자료에서 문제 만들기를 선택한다.

## 문제 생성

1. 사용자가 문제 유형을 객관식, 단답형, 주관식, 혼합형 중에서 선택한다.
2. 사용자가 제공되는 난이도를 선택한다.
3. 문제 수 등 추가로 확정된 조건이 있으면 선택한다.
4. 시스템이 중복 요청을 막고 OpenAI 기반 생성을 시작한다.
5. 생성 결과가 형식과 원문 근거 검증을 통과하면 문제 세트를 저장한다.
6. 사용자는 문제 세트의 요약을 확인하고 풀이를 시작한다.

## 풀이

1. 시스템이 현재 문제, 유형에 맞는 답안 입력, 진행 상태를 보여준다.
2. 사용자가 답을 입력하고 다음 문제로 이동한다.
3. 사용자가 마지막 답을 제출하면 시스템이 중복 제출을 막고 채점을 시작한다.
4. 객관식과 확정 가능한 답은 정답 기준으로, 서술 답은 정의된 채점 기준과 원문을 바탕으로 평가한다.
5. 결과가 준비되면 전체 요약과 문제별 결과를 보여준다.
6. 사용자는 설명과 원문 근거를 확인하고 다시 풀기 또는 학습으로 돌아갈 수 있다.

## 중단과 재개

- 앱 이탈 또는 뒤로가기 전에 풀이가 중단됨을 알리고, 정책이 허용하면 현재 답안을 저장한다.
- 미완료 풀이가 저장되면 홈의 대표 행동에서 이어 풀 수 있다.
- 재개 시 같은 문제 세트와 기존 답안을 복원한다.

## 실패와 불확실성

- 생성 실패: 조건과 자료를 유지하고 재시도 또는 원문 확인을 제공한다.
- 채점 실패: 제출 답안을 보존하며 결과 통계에 반영하지 않는다.
- 주관식 채점이 불확실함: 원문 근거와 평가 이유를 보여주고 별도의 상태로 표현한다.
- 원문 근거가 없는 생성 결과: 사용자에게 노출하기 전에 제외하거나 전체 생성을 실패 처리한다.

## 열린 질문

- 한 문제씩 즉시 채점할지 전체 제출 후 채점할지
- 풀이 중 답안 자동 저장 주기와 만료 정책
- 건너뛰기, 이전 문제 이동, 제출 전 전체 검토 허용 여부
- 불확실한 주관식 채점에 사용자 이의 제기 또는 자가 채점을 제공할지
