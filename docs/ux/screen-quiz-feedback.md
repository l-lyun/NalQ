# [Screen Spec] 서술형 자기평가와 채점 결과

## 문서 정보

- 화면명: 서술형 자기평가, 본 퀴즈·복습 채점 결과
- 문서 상태: `review`
- 대상 플랫폼: 반응형 웹과 앱 WebView, 모바일 우선
- 관련 기능: [퀴즈 생성·풀이·결과·복습](../prd/prd-quiz-learning.md)
- 관련 흐름: [퀴즈 생성부터 복습까지](flow-quiz-solving.md)
- 연관 화면: [미완료 서술형 자기평가 재진입](screen-quiz-resume.md), [틀린 문제 다시 풀기](screen-review.md)
- 시각 기준: [OpenMD Design System](../../DESIGN.md)

## 문서 책임

이 문서는 답 제출 뒤 사용자가 서술형을 자기평가하고 채점 결과를 읽은 다음 곧바로 복습 또는 홈으로 이동하는 화면 구조를 정의한다. 채점·복습 대상 정책은 퀴즈 PRD, 화면 간 분기·재개는 퀴즈 Flow, `PARTIAL`을 포함한 API 값과 결과 데이터 의미는 Contract가 책임진다.

## 목표와 완료 조건

### 사용자 목표

- 내 답과 모범 답안, 핵심 포인트, 해설과 학습자료의 관련 본문을 짧은 이동 안에서 비교한다.
- 서술형 답의 상태를 모호한 감상 표현이 아니라 다음 학습 행동과 연결되는 말로 선택한다.
- 채점 결과를 확인한 직후 미해결 문제가 있으면 다른 화면을 경유하지 않고 복습을 시작한다.

### 완료 조건

- 자기평가가 필요한 사용자는 모든 대상 문항의 평가를 저장해 결과로 이동한다.
- 결과에 복습할 문제가 있으면 `복습하기`로 해당 퀴즈의 복습 흐름을 시작하거나 이어가고, 그렇지 않으면 `홈으로` 이동한다.

## 범위와 비범위

### 범위

- 서술형 자기평가의 정보 순서, 간격, 사용자 노출 문구와 저장 행동
- 채점 결과 요약, 문항 상세의 정보 순서와 간격
- `원문 근거`의 사용자 노출 명칭 변경
- 결과 하단 `복습하기`와 `홈으로` 행동 및 상태
- 작은 WebView, 큰 글자, 키보드·보조기기와 safe area 대응

### 비범위

- 자동 채점 규칙, 점수 산식과 복습 대상 산정
- `PARTIAL` enum, `sourceExcerpt` 필드 또는 API 모양 변경
- 정확한 SEED props·import, route·mutation·캐시 구현
- 문제 풀이 입력 화면과 문제 목록 sheet의 재설계

## 요구사항 구분

### 사용자 확정 사항

- 서술형 자기평가와 채점 결과에서 컴포넌트 사이의 과도한 세로 간격을 줄인다.
- 채점 결과의 `해설`과 근거 본문을 서로 가까운 하나의 피드백 묶음으로 읽게 한다.
- 사용자 노출 제목 `원문 근거`를 `학습자료 본문`으로 변경한다.
- 채점 결과 하단에 primary `복습하기`, 일반 위계 `홈으로` 행동을 제공한다.
- `복습하기`는 채점 직후 별도의 학습 메인 경유 없이 현재 퀴즈의 복습으로 이어진다.

### 설계 제안

- `부분 이해`의 대체 문구는 `보완 필요`를 권장한다. `일부 정답`처럼 부분 점수로 오해시키지 않으면서, 다시 확인해야 하는 상태를 행동 중심으로 설명하기 때문이다.
- 사용자에게는 `정답 / 보완 필요 / 오답`을 보여주되 내부 API 값 `CORRECT / PARTIAL / INCORRECT`의 의미와 저장값은 바꾸지 않는다.
- 관련 컴포넌트 사이 세로 간격은 현재 넓은 화면 간격의 절반 수준인 SEED `x3`(12px)를 기준으로 한다. 하나의 읽기 패널 내부는 `x3`(12px) padding을 기준으로 하되 제목과 본문은 `x2`(8px)로 묶는다.
- 화면 제목·진행 정보, 피드백 묶음, 자기평가 선택, 하단 행동처럼 의미가 바뀌는 큰 그룹 사이는 `x4`(16px)까지 허용한다. 모든 간격을 동일하게 줄여 정보 위계를 없애지 않는다.
- `학습자료 본문`은 현재 결과 계약의 `sourceExcerpt`, 즉 문제와 관련된 본문 일부를 보여준다. 전체 학습자료가 모두 표시되는 것처럼 추가 설명하거나 별도 전체 본문 조회를 요구하지 않는다.

### 열린 질문

- `부분 이해`의 사용자 노출 대체 문구를 권장안 `보완 필요`로 최종 승인할지
- 복습할 문제가 0개인 결과에서도 비활성 `복습하기`를 유지할지, 이 명세의 권장안처럼 행동을 숨기고 `홈으로`만 주 행동으로 승격할지

## 진입과 이탈

| 현재 화면 | 진입 | 이탈 |
| --- | --- | --- |
| 서술형 자기평가 | 본 퀴즈·복습 제출 뒤 작성한 서술형이 있음, 또는 미완료 자기평가 재진입 | 다음 자기평가, 마지막 저장 뒤 결과, 명시적 나가기 |
| 본 퀴즈 결과 | 자동 채점과 필요한 자기평가 완료 | 문제 목록·문항 상세, 복습하기, 홈으로 |
| 복습 결과 | 복습 제출과 필요한 자기평가 완료 | 문제 목록·문항 상세, 남은 문제 복습하기, 홈으로 |

## 정보 위계

### 1. 서술형 자기평가

1. 화면 제목과 뒤로가기
2. 자기평가 진행 정보와 문제 본문
3. 첫 문항에서만 자동 점수 제외 안내
4. `내 답` → `모범 답안` → `핵심 포인트`
5. 하나의 피드백 묶음 안에서 `해설` → `학습자료 본문`
6. `내 평가`: `정답 / 보완 필요 / 오답`
7. `평가 저장하고 다음` 또는 `평가 저장하고 결과 보기`

`내 답`, `모범 답안`, `핵심 포인트`는 각각 구분하되 연속된 비교 자료로 인식할 수 있게 동일한 패널 밀도와 정렬을 사용한다. `해설`과 `학습자료 본문`은 별개의 큰 카드처럼 떨어뜨리지 않고 같은 피드백 section 안에서 가까이 배치한다.

### 2. 채점 결과

1. 화면 제목, 뒤로가기와 문제 목록
2. 채점 점수·복습할 문제 수·서술형 자기평가 요약
3. 현재 문항의 유형·번호·판정, 주제와 문제 본문
4. `내 답`·정답 또는 모범 답안·판정
5. 필요한 채점 수정 또는 핵심 포인트
6. 하나의 피드백 묶음 안에서 `해설` → `학습자료 본문`
7. 문서 흐름 마지막의 결과 행동 영역
   - 복습할 문제 1개 이상: primary `복습하기`, secondary `홈으로`
   - 복습할 문제 0개: `복습할 문제가 없어요`를 문장으로 알리고 `홈으로`를 유일한 prominent 행동으로 제공

결과 행동은 문항 상세를 충분히 읽을 수 있는 문서 흐름 하단에 두고, 작은 화면에서는 가로 2열을 강제하지 않는다. 하단 고정 영역을 사용한다면 마지막 본문과 safe area를 가리지 않는 여백을 확보한다.

## 행동과 상태

| 상태 | 사용자에게 보이는 결과 | 행동 |
| --- | --- | --- |
| 자기평가 미선택 | 세 평가 선택지가 모두 선택되지 않음 | 저장 행동 비활성, 이유를 선택 영역에서 이해 가능 |
| 자기평가 저장 중 | 현재 선택과 읽은 내용을 유지하고 처리 중 표시 | 중복 저장 방지 |
| 자기평가 저장 실패 | 저장되지 않았음을 평가 영역 가까이에 표시 | 같은 선택으로 다시 시도 |
| 결과 로딩 | 요약·문항 상세·하단 행동의 구조를 닮은 중립 Skeleton | 기다리기, 안전한 뒤로가기 |
| 결과 조회 실패 | 결과가 사라졌다고 표현하지 않음 | 같은 결과 다시 시도 |
| 복습 대상 있음 | `복습할 문제 N개`와 활성 `복습하기` | 현재 QuizSet의 활성 복습을 이어가거나 새 복습 시작 |
| 복습 시작 중 | 현재 결과를 유지하고 primary에 진행 상태 | 중복 실행 방지, `홈으로`는 데이터 변경이 없는 이탈로 유지 가능 |
| 복습 시작 실패 | 결과와 문항 상세 유지, 시작하지 못했음을 행동 가까이에 표시 | `복습하기` 다시 시도 또는 `홈으로` |
| 복습 대상 없음 | `복습할 문제가 없어요` | `홈으로` |

## 반응형·WebView

- 320 CSS px부터 한 열로 읽는다. 결과 요약만 두 열을 허용하며 긴 숫자·문구에서는 한 열 또는 행 높이 증가로 대응한다.
- 피드백 패널의 관련 컴포넌트 간격은 `x2`~`x3`, 큰 의미 그룹 사이는 최대 `x4`를 기준으로 한다. 기존 `x6` 이상의 반복 간격을 관련 정보 사이에 사용하지 않는다.
- 하단 두 행동은 공간이 충분하면 같은 폭의 2열이 가능하지만, 320px·큰 글자에서 레이블이 압축되면 `복습하기` → `홈으로` 순서의 한 열로 쌓는다.
- 고정 행동 영역은 WebView safe area, 키보드와 화면 하단을 고려하며 마지막 `학습자료 본문`을 가리지 않는다.
- 긴 한국어 문제와 본문은 잘라내지 않고 줄바꿈한다. 큰 글자에서 패널과 버튼 높이는 내용에 맞게 늘어난다.

## 접근성

- 화면마다 하나의 `h1`을 두고 문항 제목과 `내 답`, `모범 답안`, `핵심 포인트`, `해설`, `학습자료 본문`은 순서가 맞는 heading 또는 설명 관계를 가진다.
- 자기평가 선택지는 하나의 명확한 legend 아래 단일 선택 그룹으로 제공한다. `보완 필요`의 의미를 색만으로 전달하지 않는다.
- 결과 요약과 판정 변경은 적절한 live region으로 전달하되 긴 본문 전체를 다시 읽게 하지 않는다.
- `복습하기`와 `홈으로`는 각각 최소 44×44 CSS px 터치 영역과 visible focus를 유지한다.
- 복습 시작 실패 뒤 포커스는 오류 설명 또는 다시 시도 가능한 `복습하기`로 이동한다.

## SEED 역할 후보

정확한 props·variant·import는 구현 단계에서 현재 SEED Docs와 설치 버전으로 다시 검증한다.

| UI 책임 | 후보 | UX 조건 |
| --- | --- | --- |
| 문서형 단일 열과 피드백 묶음 | `Box`, `VStack`, `HStack`, `Grid`, `Text` | semantic spacing, heading 순서, related grouping |
| 자기평가 선택 | 현재 SEED의 단일 선택 form component 또는 접근 가능한 fieldset 조합 | legend, selected, disabled, error |
| 복습하기 | `ActionButton`의 brand solid 역할 | 결과의 주 학습 행동 |
| 홈으로 | `ActionButton`의 일반 secondary 역할 | primary보다 시각적으로 낮고 독립된 포커스 대상 |
| 로딩·오류 | `Skeleton`, `ResultSection`, 필요 시 `PageBanner` | 결과 보존, 복구 행동 인접 |

## 관찰 가능한 인수 조건

- [ ] 서술형 자기평가의 관련 정보 패널 사이에는 `x3`(12px) 수준, 제목과 본문 사이는 `x2`(8px) 수준의 간격이 적용되고 반복 `x6`(24px) 간격이 없다.
- [ ] 채점 결과의 문항 상세에서 `해설` 다음에 `학습자료 본문`이 같은 피드백 묶음으로 이어지며 두 영역 사이 간격이 `x3`(12px)를 넘지 않는다.
- [ ] 사용자 화면 어디에서도 해당 source excerpt의 제목으로 `원문 근거`를 표시하지 않고 `학습자료 본문`을 표시한다.
- [ ] 권장 문구가 승인되면 `PARTIAL` 상태는 자기평가 선택·요약·문항 판정에서 모두 `보완 필요`로 일관되게 표시되고, API enum은 바뀌지 않는다.
- [ ] 본 퀴즈 결과에 복습할 문제가 1개 이상이면 문서 흐름 하단에 brand 위계 `복습하기`와 일반 위계 `홈으로`가 함께 보인다.
- [ ] `복습하기`는 현재 QuizSet의 활성 복습을 이어가거나 새 복습을 시작하며 학습 메인을 경유하지 않는다.
- [ ] 복습 시작 중 중복 요청이 발생하지 않고 실패해도 현재 채점 결과와 문항 위치를 잃지 않는다.
- [ ] 복습할 문제가 0개면 불가능한 복습 route를 만들지 않고 완료 안내와 `홈으로`를 제공한다.
- [ ] 320 CSS px와 큰 글자에서 두 행동은 필요 시 한 열로 쌓이고, 본문·버튼이 WebView safe area나 키보드에 가리지 않는다.
