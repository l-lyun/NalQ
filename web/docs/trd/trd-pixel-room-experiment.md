# [TRD] 도트 캐릭터 걷기·모자 레이어 실험

## 목적과 경계

캐릭터 꾸미기 제품 범위를 구현하기 전에, 캐릭터 3종의 짧은 좌우 걷기와 공통 모자·옷 레이어 정렬, 방 2종 교체가 현재 React 웹에서 자연스럽게 동작하는지 확인한다. 개발 모드의 `/experiments/pixel-room`에서 로그인 없이 접근하며 프로덕션 라우트에는 포함하지 않는다.

이 실험은 실제 홈·마이페이지, 상점, 코인, 보상, 구매, 로그인, API와 영속 저장을 변경하지 않는다. 캐릭터·방·모자·옷 선택은 페이지를 닫으면 사라지는 서로 독립된 React 로컬 상태다. 캐릭터나 방을 바꿔도 선택한 모자와 옷은 초기화하지 않아 공통 자산의 정렬을 바로 비교할 수 있다.

## 자산과 합성

- `room-day.png`, `room-night.png`: 동일한 걷기 영역을 공유하는 낮·밤 공부방 배경이다.
- 캐릭터 자산: `dragon-alpha.png`, `cat.png`, `bear.png` 투명 PNG를 같은 1254×1254 표시 좌표계에서 사용한다.
- 모자 자산은 투명 PNG 한 벌을 세 캐릭터가 공통 아이템 ID로 공유하고, `PixelSprite`가 캐릭터별 머리 위치에 맞춘 등록 좌표로 배치한다.
- 크림 니트는 용·고양이·곰마다 `*-sweater.png` 착용 이미지를 한 장씩 사용한다. 전체 착용 이미지를 기본 캐릭터 대신 표시하면 AI 재생성 차이로 몸 크기가 달라질 수 있으므로 기본 캐릭터의 머리·날개 또는 꼬리·발은 항상 유지하고, 착용 이미지의 몸통 영역만 합성한다.
- 몸통 영역은 용의 직사각형 `(310, 620, 625, 400)`과 고양이·곰의 팔·밑단을 따르는 캐릭터별 다각형으로 등록한다. 각 몸통을 해당 기본 캐릭터 PNG의 alpha 실루엣과 교차시켜 불투명 픽셀이 원래 외곽 밖으로 확장되지 않게 한다. 고양이·곰 착용 자산은 반복된 투명 추출 뒤에도 RGB 체크 무늬가 남아 있어, 다각형은 니트 안쪽만 제한하는 실험용 보정도 겸한다. 정식 자산은 검수된 alpha PNG로 교체해야 한다.
- 이 방식은 캐릭터별 착용 자산이 필요하며, 한 장의 옷 이미지가 서로 다른 체형에 자동 호환됨을 의미하지 않는다.
- 이동·방향·크기는 `PixelSprite` 바깥 장면이 맡아 자산 표시 보정과 움직임 계산을 분리한다.
- 모든 도트 자산은 `image-rendering: pixelated`로 표시한다.
- 현재 캐릭터 PNG는 실제 걷기 atlas가 아니다. `PixelSprite`가 캐릭터별 발 기준선 아래를 좌우로 나눠 네 단계에서 `±9px` 이동시키는 cutout 셔플로 걷는 인상만 검증한다. 세 캐릭터 모두 니트를 입어도 각 기본 캐릭터의 발 셔플을 사용하고 모자는 별도 레이어로 유지한다. 상체·옷·모자는 고정되며, 제품용 애니메이션에는 아티스트가 등록점을 맞춘 프레임 자산이 필요하다.
- 생성 도구·크기·프롬프트는 [자산 기록](../../src/experiments/pixel-room/assets/README.md)에 보관한다.

## 움직임 상태

정규화 위치 `0..1`, 방향 `-1 | 1`, 실행 상태와 누적 보행 시간을 상태로 둔다. 프레임 시간으로 이동 거리를 계산하고 경계를 넘은 잔여 거리만큼 반대 방향으로 되돌려 낮은 프레임에서도 벽 밖으로 나가지 않는다. 브라우저 탭 복귀 시 큰 시간차로 캐릭터가 튀지 않도록 화면의 프레임 입력은 64ms로 제한한다.

사용자는 캐릭터 3종, 방 2종, 기본 옷·크림 니트, 모자 세 가지와 왼쪽·오른쪽 보기, 일시정지·재개를 터치 또는 키보드로 선택한다. `prefers-reduced-motion: reduce`에서는 자동 이동과 걷기 프레임을 정지하고 캐릭터·방·방향·옷·모자 미리보기만 유지한다.

## 검증

- 모션 모델 단위 테스트: 경계 반전, 긴 프레임 지연, 일시정지·재개, 모션 감소, 프레임 순환
- 320px 이상 모바일 폭과 640px 최대 본문 폭에서 가로 넘침 확인
- 터치·키보드 버튼 조작과 선택 상태의 텍스트·`aria-pressed` 확인
- `pnpm verify`로 라이선스, 타입 검사, lint와 production build 확인

### 2026-09-07 초기 1종 실험 결과

- PASS: `node --test src/experiments/pixel-room/pixelRoomMotion.test.mjs` 5개, `pnpm typecheck`, `pnpm lint`, `pnpm build`.
- PASS: 브라우저에서 걷기 프레임·위치 변화, 정지·재개, 모자 3개 상태, 좌우 반전, 키보드 Enter 선택 확인. 320·390·768·1440px에서 가로 넘침 없이 넓은 화면 본문 640px 확인. 조작은 SEED large 버튼으로 최소 44px 이상 확보.
- PASS: production build 산출물에 실험 route·캐릭터/모자/방 자산이 포함되지 않음.
- PASS: 용의 기본 옷과 크림 니트를 같은 정지 위치에서 비교해 외곽·머리·발 크기가 유지되고 몸통 옷만 바뀌는 것을 확인했다. 베레모 재착용과 걷기 재개에서도 원본 외곽을 유지했다.
- PRE-EXISTING FAILURE: `pnpm verify`의 `licenses:check`가 `Third-party notices are out of date`로 중단. 이 브랜치는 dev의 package/lock/고지 파일을 변경하지 않았다. 나머지 검사는 개별 실행했다.
- BLOCKED: 실제 iOS/Android WebView와 기기의 모션 감소 설정은 이 환경에서 미검증. 모션 감소 분기는 단위 테스트로만 검증했다.

## 실행

### 2026-09-07 캐릭터·방 선택 확장 결과

- PASS: 모션 모델 5개 테스트, `pnpm typecheck`, `pnpm lint`, `pnpm build`.
- PASS: 3종 × 2개 방 전환에서 모자·니트·멈춤 상태 유지. 기본 옷 전환, 비니·베레모 교체와 키보드 Enter 걷기 재개 확인.
- PASS: 브라우저에서 세 캐릭터의 기본 옷·니트를 비교해 각 캐릭터의 base·feet·alpha mask가 자기 원본으로 유지되고 표시 너비가 바뀌지 않음을 확인했다. 고양이·곰 니트의 체크 무늬 경계 노출 없이 베레모·니트 착용, 이동 위치·프레임 갱신과 정지 프레임 0이 정상이다. 320px·390px 가로 넘침 없음, 1440px에서 본문 640px 확인.
- PRE-EXISTING FAILURE: `pnpm verify`는 기존 third-party notices 불일치로 중단. 개별 검사는 위와 같이 실행.
- 실제 iOS/Android WebView와 모든 프레임 조합의 픽셀 단위 의상 호환 검수는 미완료. 이번 결과는 개발 전용 조합 실험이다.

`web/`에서 `pnpm dev --host 127.0.0.1 --port 5178 --strictPort`를 실행하고 `http://127.0.0.1:5178/experiments/pixel-room`을 연다. 로그인과 서버 API 없이 실험할 수 있다. 원본 dev 기능은 기존 경로에서 유지한다.
