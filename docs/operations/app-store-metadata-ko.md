## 설명

읽고 끝내지 말고, 내 자료로 풀어보세요.

NalQ는 내가 가진 글을 AI 퀴즈로 바꾸고, 문제 풀이와 복습으로 이해도를 확인하는 학습 앱입니다. 정리해 둔 내용을 다시 읽는 데서 한 걸음 더 나아가, 무엇을 알고 무엇을 다시 살펴봐야 하는지 확인해 보세요.

내 자료를 학습의 시작으로
텍스트를 붙여넣거나 연결한 Notion의 페이지를 가져와 학습자료로 저장하세요. 가져온 내용을 확인하고 수정한 뒤 문제를 만들 수 있습니다.

나에게 맞는 퀴즈 만들기
객관식, 빈칸 채우기, 단답형, 서술형 중 원하는 유형을 선택하세요. 난이도와 최대 문제 수를 정해 자료에 맞는 퀴즈를 만들 수 있습니다.

풀고, 확인하고, 다시 이해하기
문제를 푼 뒤 결과와 자료의 관련 내용을 확인하세요. 서술형은 모범 답안과 핵심 포인트를 보며 직접 평가합니다. 가장 최근에 완료한 퀴즈에서 틀린 문제는 다시 풀어볼 수 있습니다.

학습 흐름을 한곳에서
홈에서 이어서 할 학습을 확인하고, 학습 화면에서 자료와 퀴즈를 관리하세요. 문제 만들기부터 풀이와 복습까지 하나의 흐름으로 이어집니다.

이용 안내
회원가입과 인터넷 연결이 필요합니다. Notion 자료 가져오기는 선택 사항이며, 선택한 페이지를 한 번 복사하는 방식입니다. AI 문제 생성 시 학습자료와 생성 조건이 OpenAI에 전송됩니다. AI가 만든 문제와 답에는 오류가 있을 수 있으니 원문과 함께 확인해 주세요.

## TestFlight 테스트 정보

### 베타 앱 설명

NalQ는 내 글과 Notion 페이지를 바탕으로 AI 퀴즈를 만들고, 문제 풀이와 복습으로 이해도를 확인하는 학습 앱입니다. 이번 테스트에서는 가입·로그인, 자료 만들기, 퀴즈 생성·풀이·복습과 앱 알림 동작을 확인합니다.

### 테스트할 내용

1. 회원가입과 로그인 후 앱을 다시 열었을 때 이용 상태가 정상적으로 유지되는지 확인해 주세요.
2. 텍스트를 붙여넣어 학습자료를 만들고 퀴즈를 생성해 주세요. Notion 연결은 선택 사항입니다.
3. 퀴즈를 풀고 결과를 확인한 뒤, 틀린 문제를 다시 풀어 주세요.
4. 알림을 허용한 뒤 문제 생성을 요청하고 앱을 백그라운드로 보냈을 때 알림이 도착하는지 확인해 주세요. 알림을 눌렀을 때 해당 결과로 이동하는지도 확인해 주세요.
5. 로그아웃 뒤 이전 계정의 알림이나 내용이 표시되는지 확인해 주세요.

문제가 발생하면 이용 기기, iOS 버전, 발생 시각과 재현 순서를 nalq.service@gmail.com으로 알려주세요. 비밀번호나 개인 학습자료 원문은 보내지 않아도 됩니다.

### 심사 메모 초안

NalQ는 회원 계정으로 학습자료를 저장하고 AI 퀴즈를 생성·풀이·복습하는 학습 앱입니다. Notion 연결 없이 텍스트 입력만으로 핵심 기능을 확인할 수 있습니다. 서술형 평가는 AI 자동 채점이 아닌 사용자 자기평가입니다. 계정 삭제는 마이페이지의 계정 관리에서 진행할 수 있습니다.

심사용 운영 계정은 별도로 준비해야 합니다. 로컬 테스트 계정은 운영 서버에서 사용할 수 없으므로 심사 계정으로 입력하지 않습니다. 심사 로그인 정보, 연락처 전화번호와 기타 비공개 정보는 이 문서에 저장하지 않습니다.

## 아이콘과 제출 범위

앱 아이콘은 기존 스플래시의 주황색 용과 Q를 바탕으로 만든 불투명 정사각형 자산을 사용한다. 아이콘 구성은 [iOS 배포 준비](../../app/docs/ios-distribution.md)를 따른다. 스크린샷은 실제 앱의 최종 화면을 촬영해 등록해야 하며 생성 이미지로 실제 화면을 대신하지 않는다.

나이 등급, 개인정보 수집 항목, EU 거래자 여부와 계약은 설명 문구만으로 추정해 확정하지 않는다. 현재 제품에는 친구·랭킹·경험치, 파일 업로드, Notion 자동 동기화가 없으므로 홍보 문구에 포함하지 않는다. 푸시 수신은 검증 전이므로 공개 설명의 확정된 장점으로 약속하지 않는다.

## 적용 기록

- 2026-09-08: App Store Connect 한국어 설명·프로모션 문구·키워드·지원/마케팅 URL·저작권·심사 메모를 저장했다. 부제와 교육 카테고리, 개인정보처리방침 URL도 저장했다.
- TestFlight 베타 앱 설명·피드백 이메일·마케팅/개인정보처리방침 URL을 저장했다. 빌드 3에는 아이콘·로그인 유지·푸시 수신·알림 탭 이동 테스트 항목을 저장했다. 심사 계정 정보는 입력하지 않았다.
- 사용자가 소개 작업보다 본인 계정의 TestFlight 설치·푸시 검증을 우선하도록 범위를 조정했다. 추가 소개·심사 자료 작업은 중단하고 내부 테스트 준비를 진행한다.
- EAS 1.0.0 (2)는 기존 provisioning profile의 Push Notifications / aps-environment 누락으로 실패했다. 이후 새 profile과 APNs 키를 EAS에 연결했고, 아이콘 포함 1.0.0 (3) 빌드·업로드 및 본인 iPad 설치를 확인했다. 실제 푸시 수신 검증은 남아 있다. 상세 증거는 [iOS 배포 기록](../../app/docs/ios-distribution.md)에 기록한다.
